# 37 · 无感 FOC 使用指南

> 适用固件：**#146** 及以后。
> 相关文档：`34_无感FOC实施方案`（设计）、`30_命令手册`（命令表）、`36_master已知问题`（历史）。

---

## 1. 三句话说明

无感模式下，**角度和转速都由反电动势观测器提供**，编码器只用来对照验证。
启动分两段：先 **I/f 开环拖动**把转子带起来，再**交接**给观测器闭环。

```
静止 ──I/f 拖动──► 250 rpm 以上 ──交接──► 观测器闭环（无感）
     (d 轴对齐 400ms + q 轴逐步加速)
```

**最低可用转速：约 300 rpm**（再低反电动势太弱，观测器不可靠）。

## 2. 标准操作流程

### 2.1 上电后

```bash
ver            # 确认固件版本（当前 #163）
mode 2         # FOC 模式
start          # 使能桥臂
```

> #147 起 `sfoc go` 会**自动打开观测器**，不用手动 `obs on`。
> 想看影子波形时再单独 `obs on` 即可。

### 2.2 起转 + 自动交接

```bash
sfoc go 300
```

日志：`OK sfoc go 300.00 rpm; I/f then hand over`

然后观察：

```bash
sfoc
```

输出示例：

```
sfoc done, blend 1.00, ds 57.0 deg, sensorless 1
 diag: if run 0 phase 0 f 2.0 Hz, ho cnt 400, |e|/exp 0.90
 obs w 599 rpm, enc 598 rpm, eq 1.61 V, locked 1
```

| 字段 | 含义 |
|---|---|
| `state` | `watching`（等条件）→ `blending`（渐变）→ **`done`（交接完成）** |
| `sensorless` | **1 = 观测器已接管角度与速度** |
| `obs w` | 观测器估计转速 |
| `enc` | 编码器实测转速（**验证用**，两者应接近） |
| `eq` | 反电动势幅值，随转速线性增长 |
| `locked` | 观测器 PLL 的瞬时锁定标志（**仅供观察，不参与判据**） |
| `diag` | `if run/phase/f`=I/f 状态；`ho cnt`=交接去抖计数；`\|e\|/exp`=幅值与期望之比（约 0.9 为正常） |

> ⚠️ **`spd` 本身不区分有感/无感**：
> - 只 `mode 2` + `start` + `spd 600` → 用的是**编码器**速度环（有感）
> - `sfoc go` + 交接完成（`sensorless 1`）之后再 `spd 600` → 用的是**观测器**速度（无感）
>
> #165 起回复会直接写明反馈源：`OK spd target = 600 rpm (encoder)` /
> `OK spd target = 600 rpm (observer)`。**`spd` 不会自动切模式**：
> 想从无感回到有感，先 `sfoc off`（打印 `OK sfoc off (encoder mode)`）再 `spd <rpm>`。
>
> 用 `sfoc` 看一眼 `sensorless 1` 就知道当前在哪个模式。

### 2.2b 无编码器运行（没有装编码器）

板子没装编码器、或编码器坏了，先关掉编码器子系统：

```bash
enc off      # 停用编码器：不读帧、不做断线检测、不置 valid
mode 2
start
sfoc go 400  # 正常起转（角度与速度全部来自观测器）
```

> 为什么必须 `enc off`：编码器拔掉后 SPI 读回**全零**，
> 而 `CRC6(0) == 0` 恰好通过校验 → `raw` 恒为 0 →
> 触发"编码器断线检测"（连续 200 帧 raw==0）→ `FAULT_ENCODER`。
> 那个保护对有编码器的场合是对的，无感场合必须关掉。

关掉之后：

| 项 | 行为 |
|---|---|
| `enc` | 显示 `no frame yet`（`valid` 被清零） |
| 角度 / 速度 | 观测器 |
| 过速 / 堵转保护 | 用观测器速度 |
| 有感模式（`spd` 不配 `sfoc`） | 不可用（没有角度源） |

**实测（#160，编码器已拔）**：起转 3/3（约 2.0 秒），
500/700/900/1100/1300/1500 rpm 全部精确跟踪，无故障。

### 2.2c 反转（#170 / #171）

\sfoc go\ 与 \spd\ 都接受负转速，绝对值仍要 >= 300 rpm：

\sfoc go -400      # I/f 反向拖动 -> 交接 -> 反向无感闭环
spd -900          # 已在无感态时直接改目标
sfoc go -1200     # 更快
\
- 反向起转时 \lg_if\ 直接从 **-2 Hz** 起步（#170），不会再先正着抖一下。
- 交接的转矩预载使用**有符号**角差（\sfoc\ 查询里的 \ds\：正向约 +94 度，
  反向约 -59 度），反向时预载负电流，交接不甩。
- **#171 起反向闭环可用**：\sfoc go -400\ / \-900\ 实测稳定在 -405 / -906 rpm，
  电流 0.07 A。反向时速度环内部把 \iq\ 取反 —— 观测器坐标系里的反向转矩符号
  与正向相反（反向拖动用 +0.6 A 得到的是反向转矩）。
- 换向（+400 → -400）**建议先 \sfoc go 0\** 滑行再发反向命令；直接跨零改目标会经过
  “反电动势过零、观测器无信号”的区间，实测 1.1 s 后 \ERR obs lost lock\ 安全释放
  （从 -900 直接给 +400 则是成功的，越高速越容易过去）。

### 2.3 调速

```bash
spd 600        # 目标 600 rpm（速度环用观测器速度）
spd            # 查看 ref / meas
```

### 2.4 停机

```bash
spd 0          # 速度目标归零，释放电流，但仍在无感闭环里（见下）
sfoc off       # 退出无感：清 s_sfoc/s_ho_state，无编码器时连速度环一起停
stop           # 关断桥臂
```

> `stop` 之后速度估计会自动清零（`pll clears` 计数 +1）。

#### `spd 0` 之后算不算退出无感？（实测问过两次）

**不算。** `spd 0` 只调 `app_spd_off()`，清掉速度环与电流指令，**不清 `s_sfoc`**。
之后固件仍处在观测器闭环里，只是给零电流让转子惰行：

| 情况 | 再发 `spd 200` / `sfoc go …` 的结果 |
|---|---|
| 转子**还在转**（反电动势幅值 E 还有值） | 原地接回闭环，角度无缝，不需要重新起转 ✅ |
| 转子**已经停稳**（E ≈ 0） | 观测器没有反电动势可测，`θ̂` 不前进，只把速度环重新打开是起不来的 ❌ |

所以"能不能直接加速"取决于**转子停没停**，而不是"发没发过 `spd 0`"。
真正要停一会儿再起转，用 `sfoc off` → `sfoc go <rpm>`（或 `stop` → `start` → `sfoc go`），
这两条路都会清掉无感状态，下一次 `sfoc go` 才会重新走 I/f。

> **#173 起**：`spd 0` / `sfoc go 0` 之后转子滑行到停，日志会打一行
> `OK rotor stopped, sensorless released`（以前误报成 `ERR obs lost lock`）。
> 这只是在告诉你转子已经停了、无感状态已退出，不是故障。

## 3. 状态机

```
       sfoc go <rpm>
idle ───────────────► watching ──(条件满足 20ms)──► blending ──(100ms)──► done
 ▲                       │                            │                  │
 │                       │  条件不满足则继续等          │                  │
 └───────────────────────┴────────────────────────────┴──────────────────┘
                          sfoc off / app_ho_arm
```

**交接条件**（三个同时满足，持续 20 ms）：

| 条件 | 阈值 | 含义 |
|---|---|---|
| `\|e\|`（矢量幅值） | > 0.5 V | 反电动势足够大 |
| `\|e\|` / 期望值 | > 0.5 | 期望 = 拖动转速换算的 `ω·ψf` |
| I/f 拖动转速 | > 250 rpm | 已脱离低速区 |

> ⚠️ 两个关键点：
> 1. 用 **`\|e\| = √(eα²+eβ²)`**，不是 `eq`——`eq` 是投影分量，
>    角度差接近 90° 时会塌陷成 0，用它会令交接"时好时坏"。
> 2. 期望值用 **拖动指令转速**换算，不是观测器自己的转速——
>    否则就是"用观测器验证它自己"，它一漂判据永远不成立（#163）。

> ⚠️ 判据**不是**"观测器角度与 I/f 框架一致"——拖动本身有约 74° 的负载角，
> 那是物理现象，不是误差（见 `docs/00` 2026-10-31 的交接诊断）。

## 4. 常用命令速查

| 命令 | 作用 |
|---|---|
| `obs on` / `obs off` | 开/关观测器（`sfoc go` 会自动打开，无需手动） |
| `obs` | 看观测器状态：`ed/eq/theta/角度误差/locked` |
| `obs bw <hz>` | 观测器 PLL 带宽（默认 80） |
| `obs lpf <hz>` | 反电动势低通（默认 1500，`0` = 关闭） |
| `obs comp <0\|1\|2>` | 相位补偿模式（默认 2 = 滞后） |
| `obs trim <deg>` | 恒定角度校正（默认 −3.6） |
| `sfoc go <rpm>` | I/f 起转 + 自动交接；**已无感时等同于调速** |
| `sfoc` | 看交接状态 |
| `sfoc off` | 退出无感，回编码器 |
| `sident [r / l / ke / hf / all / stop]` | 自动辨识 R / L / KE 并打印 `motor_cfg.h` 建议整数（换电机用，S10.7）；`hf` = 2 kHz 注入测 L，实测 0.50 mH 与手册一致 |
| `spd <rpm>` / `spd off` | 速度环（无感下反馈取自观测器） |
| `if <rpm>` / `if off` | 只做 I/f 拖动，不交接（调试用） |
| `if i <A>` / `if acc <hz>` | 调拖动电流 / 频率斜率 |
| `wave on [hz]` | 波形上报；21 通道用 `wave on 250`（500 Hz 会溢出，见 #167） |

## 5. 参数（`board_cfg.h`）

### I/f 起转

| 宏 | 默认 | 说明 |
|---|---|---|
| `IF_ALIGN_MS` | 600 | d 轴预对齐时长（**消除 180° 起始歧义**；#166 从 400 放软到 600） |
| `IF_I_RAMP_MS` | 300 | 预对齐电流斜坡时长（#166；原来 100 ms 会甩一下） |
| `IF_XFADE_MS` | 80 | d→q 交叉淡入时长（#166；消掉矢量 90° 阶跃） |
| `IF_I_AMP_A` | 0.60 | 拖动电流（0.4 A 临界，实测 0.6 A 起 10/10 成功） |
| `IF_ACC_HZ_S` | 30 | 频率斜率（约 1.1 s 到 300 rpm） |
| `IF_F_MIN_HZ` | 2.0 | 起始电频率 |

### 交接

| 宏 | 默认 | 说明 |
|---|---|---|
| `HO_MIN_RPM` | 250 | 交接所需最低转速 |
| `HO_HOLD_MS` | 20 | 条件需持续多久 |
| `HO_BLEND_MS` | 100 | 角度渐变时长 |
| `OBS_E_MIN_V` | 0.5 | 交接所需最小反电动势 |

## 6. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `sfoc go` 后一直 `watching` | 转速没到 250 / `\|e\|` 太小 / `\|e\|/exp` 比例低 | 看 `sfoc` 的 `diag` 行；提高目标转速 |
| 起转时转子抖动、不转 | 电流太小 | `if i 0.8` 再试；或检查 `IF_ALIGN_MS` 是否为 0 |
| 起转方向反了 | 目标为负 | `sfoc go -300` |
| 交接后转速跑飞 | 速度环没启动 | 确认 `sensorless 1`；必要时 `spd 300` 重新给目标 |
| 交接后转速不稳 | 观测器带宽不合适 | `obs bw 60` 或 `obs bw 120` 对比 |
| `obs w` 与 `enc` 差很大 | 参数/标定不对 | 检查 `obs trim`；换电机需重标 |
| `ERR obs off, run =obs on= first` | 早期固件（< #147）才需要手动开 | 升级到 #147 以上，`sfoc go` 会自动开 |
| 起转时电机"抖/甩"一下 | 预对齐把转子拉到 d 轴（无转矩，只是定位），属正常 | #166 起已放软（电流 300 ms 斜坡、d→q 交叉淡入 80 ms、交接 PI 预置）：实测交接甩动已消失，起转只剩一次轻微摆动，属机械上不可避免的定位 |
| `ERR fault encoder invalid`（`start` 后立刻出现） | #163 及更早：没装编码器时 `start` 会跳闸 | 升级到 **#164**：会自动 `enc off` 并打警告，`sfoc go` 照常可用 |
| `sfoc off` 时电机被猛拽一下 / 跳 `overcurrent` | #167 及更早：没有角度源时命令三相同占空比 = 三相短路，反电动势灌进绕组（1500 rpm 实测 1.32 A） | 升级到 **#168**：还有反电动势时按零电流闭环滑行，转子停稳后才放开 |
| 故障或 `stop` 之后再 `start`，电机**完全不动**，`iq_ref` 打满、`vq` 顶到轨、`sfoc` 仍显示 `sensorless 1` | #171 及更早：故障/停机没有退出无感与 I/f 状态，恢复时用了**故障前的陈旧观测角** | 升级到 **#172**：故障与停机都会释放无感/交接/I/f 并复位观测器 |
| `ERR start first` | 桥臂没使能 | 先 `mode 2` + `start` |
| `ERR rotor still turning, wait for it to stop` | 上一轮 `sident` 的 KE 段让转子转起来了，零电流滑行几乎不减速 | 等 1~2 s（#178 起 KE 段结束会主动刹车，正常不会出现） |
| `ERR bus ... V, wait for it to settle` | 母线高于 13.0 V，辨识会半路跳过压 | 等母线回落到 12 V 左右再发 `sident` |
| 换电机后交接一完成就失步或过流，`obs w` 自己往 1000+ rpm 飞 | 观测器的相位补偿是按旧电机 L 标的 | 装上编码器后按 `## 9` 重标 `obs trim` / `obs comp` / `obs bw`（见 docs/00 的 #182 条目） |
| `enc` 打印 `raw 0, mg 0, crc ok, nz 0` | MISO 线上没有数据在跳（3V3 / SCK / CS / MISO 任一根断或没供电）；全零帧的 CRC 恰好也是 0，所以 `crc ok` 是假象 | 量芯片端 3.3 V，示波器看 PB4 在转动时有没有跳变，查排线与磁铁间隙；`start` 会打印 `warn encoder silent: no data on MISO` |

## 7. 注意事项

| 项 | 说明 |
|---|---|
| **最低转速** | 约 300 rpm；以下反电动势太弱，只能 I/f 开环 |
| **需要编码器吗** | 不需要。编码器只是**验证**用途，可随时拔掉（`sfoc` 里的 `enc` 会变成 0） |
| **`sfoc off` 之后** | 有编码器：立刻回到编码器角度闭环，不会掉步。无编码器（#168）：按 `id=iq=0` 滑行到停，不短路、不硬刹；#169 起还会解除速度环（不再残留目标转速），滑行期 ch8/ch9 继续显示观测器角度/频率 |
| **堵转保护** | 无感下速度来自观测器，堵转判据可能不敏感；可靠的是电流限流 1.20 A 与过流跳闸 1.28 A |
| **`spd off`** | 只释放电流（iq=0），不退出无感；再给 `spd` 即可继续 |
| **掉电重启** | 观测器标定值烧在固件里，不会丢（编码器零位同理，存在 flash） |

## 有感 / 无感 切换对照（#165）

| 想要 | 命令 | 反馈源 |
|---|---|---|
| 有感调速 | `mode 2` → `start` → `spd 500` | 编码器（回复 `(encoder)`） |
| 无感调速 | `mode 2` → `start` → `sfoc go 500` | I/f → 观测器 |
| 无感调目标 | 交接后再 `sfoc go 800` / `spd 800` | 观测器（回复 `(observer)`） |
| 无感回到有感 | `sfoc off` → `spd 500` | 编码器 |

两条硬约束：

1. **`sfoc go` 低于 300 rpm 直接拒绝**：`ERR sensorless needs |rpm| >= 300`。
   反电动势太小，观测器锁不住（`SFOC_RPM_MIN`，板级配置可调）。
2. **没有编码器时 `spd` 会报错**：`ERR no encoder: use 'sfoc go <rpm>' or 'enc on'`。
   以前是回 `OK` 但电机不动（零矢量保持挡住了速度环输出）。

## 9. 换电机怎么开始（S10.7）

1. 改 `User/Cfg/motor_cfg.h`：`pp`、`i_rated_a`、`i_max_a`、`rpm_max`，其余先留旧值
2. `mode 2` -> `start` -> `sident`，等约 4 秒：电机会先被拉到固定位置（只是定住，不转），
   然后慢速拖动一次测反电动势
3. 把打印的 `motor_cfg.h:` 那一行三个整数填回文件，重新编译烧录
4. `align ol` 连做 10 次确认定位可重复，然后 `sfoc go 300` 起转
5. 扫 300 / 600 / 900 / 1200 rpm，再反向 -300 ... -900
6. 最后再跑一次 `sident ke`：两次 KE 相差应 < 10%，否则先查母线电压与相电阻

`motor_cfg.h:` 那一行只列**测到的量**：默认 `sident` 只做 R + KE，所以只有 `r_ohm` 和
`ke_v_rad_s`，**没有 `l_h`** —— L 不是忘了打，是测不准：这台电机 L/R 只有 217 us，
20 kHz 下只有 4 个采样点（实测 0.29 mH 对手册 0.50 mH）。L 请照手册填。
要自己看那个数就发 `sident l`，输出会带 `experimental` 字样。

连跑前先看一眼母线：KE 段会把动能灌回母线，连跑三次可能跳 `ERR fault overvoltage`。
#175 起 `sident` 启动时若母线超过 13.0 V 会直接拒绝（`ERR bus ... V, wait for it to settle`），
等半秒再发一次即可。

细节与判据见 `34_无感FOC实施方案.md` 的 §S10.7。
