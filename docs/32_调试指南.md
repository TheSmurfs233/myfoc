# 32 · 调试指南

> 面向"电机不动 / 抖动 / 读数不对"这类现场问题，按症状查表。

## 0. 一分钟自检

```bash
ver      # 固件版本 + 编译时间
stat     # state / mode / pwm / adc / loop
fault    # 最近故障 + 计数
vbus     # 母线电压
enc      # 编码器角度与 CRC
cur      # 三相电流
```

五条命令基本能定位 80% 的问题。

---

## 1. 电机完全不转

| 检查 | 命令 | 正常值 | 异常处理 |
|---|---|---|---|
| 是否使能 | `stat` | `pwm = ON`、`state = RUN` | `mode 2` + `start` |
| 是否故障 | `fault` | `fault none` | `stop` 清除后重试 |
| 母线电压 | `vbus` | 11~13 V | 检查电源/接线 |
| 电流是否给出 | `cur` | 与 `iq` 指令相符 | 检查三相线序 |
| 编码器 | `enc` | `crc ok`、角度随转动变化 | 见第 6 节 |
| 是否在电流模式 | `stat` | `mode = FOC` | — |

**常见原因**：`iq 0.05` 太小（低于维持转动的 0.04 A 门槛）；`spd` 目标为 0。

---

## 2. 电机抖动 / 异响

按转速分段排查：

| 转速段 | 现象 | 首查项 |
|---|---|---|
| **≤50 rpm** | 哒哒哒（粘滑） | `prot st` 是否误配；kick 参数（`SPD_KICK*`） |
| **50~200 rpm** | 轻微脉动 | `rip` 看 iq 峰峰值；滤波 `SPD_LPF_*` |
| **200~1000 rpm** | 周期性抖动 | `rip` + `pll` 对比窗口/PLL 测速 |
| **>1800 rpm** | 明显振动 | **多为机械**（见第 5 节）或电压饱和 |

### 诊断工具

```bash
rip                  # 500 ms 内 iq 与转速的峰峰值
pll                  # 两种测速的实时值
foc                  # id/iq/vd/vq/调制比 m
```

**性能基线**（PLL 14 Hz + kp 0.006/ki 0.080）：

| 目标 | iq 峰峰 | 转速脉动 |
|---|---|---|
| 100 rpm | ~0.07 A | ~5 rpm |
| 500 rpm | ~0.08 A | ~14 rpm |
| 800 rpm | ~0.06 A | ~11 rpm |
| 1200 rpm | ~0.05 A | ~9 rpm |

若明显超标：先 `pll` 确认测速源与带宽，再 `spi` 检查增益是否被改过。

### 增益越界的表现

| 参数 | 过大 | 过小 |
|---|---|---|
| `spi` kp >0.016 | 电流纹波暴涨（2 A 级）、机械摆动 | 响应迟钝 |
| `spi` ki >0.15 | 低频振荡 | 稳态误差大 |
| `pi` kp 过大 | 电流环啸叫 | 跟随慢 |

## 3. 高速上不去 / 到某个转速就停住

**先算物理上限**：

```
最高转速 ≈ (0.5 × Vbus × 0.95) / (K_emf × 7 × 2π / 60)
12 V 时 ≈ 1900 rpm
```

| 现象 | 原因 |
|---|---|
| 设 2000 只能到 ~1900 | 电压饱和（`foc` 里 m=0.95）—— **物理限制** |
| 设 1500 只能到 1200 | 负载过重或母线电压低 |
| 转速上去后电流反而变小 | 电压限幅生效，属于正常 |

**提升办法**：提高母线电压、换低 KV 电机、减轻负载。

---

## 4. 电流/电压读数异常

| 现象 | 检查 | 处理 |
|---|---|---|
| 静止时电流不为 0（>50 mA） | `cur` 看零漂 | `stop` 后 `cal` 重新标定 |
| 电流方向相反 | `cur` 三相符号 | 检查相线/分流器 |
| `vbus` 读数为 0 或 BAD | `vbus` 状态 | 检查分压电阻与 PA1 接线 |
| `vbus` 与万用表差 >0.2 V | — | 实测 VDDA 后修改 `ADC_VREF` |

---

## 5. 高速振动大（>1800 rpm）

**优先怀疑机械**（电学指标此时通常很好）：

```bash
foc        # 若 m ≈ 0.95，说明已进电压饱和
rip        # 若 iq 峰峰 <0.1 A 而抖动仍在 -> 机械问题
```

| 机械原因 | 对策 |
|---|---|
| 转子动平衡差 | 做动平衡，或降低最高转速 |
| 轴承不适合高速 | 换轴承 |
| 测试支架共振 | 加固、加阻尼、改变安装 |
| 负载偏心 | 重新装配 |

---

## 6. 编码器问题

| 现象 | 检查 | 说明 |
|---|---|---|
| `enc` 显示 `crc ok` 但角度不动 | 拔线 | MISO 拉低时全 0 帧的 CRC 也是 0（**盲区**），靠"200 帧 raw==0"识别 |
| CRC 错误率高 | `enc` 的 `err = x/y` | `wave on` 时会升高（EMI），属已知现象 |
| 角度方向反了 | `enc dir 1` | — |
| 电角度零位不对 | `align` | 会强制对齐并写 flash |
| `late` 计数增长 | — | DMA 错过采样时隙，检查 SPI 时序 |

---

## 7. 保护误触发

| 保护 | 误触发原因 | 处理 |
|---|---|---|
| 过流 | 阈值太靠近限幅（默认 1.28 vs 1.20） | `prot oc` 适当提高或降低 `FOC_I_MAX_A` |
| 堵转 | 目标转速过低（<30 rpm）且在速度环 | 提高目标或降低 `prot st`/`prot siq` |
| 超速 | 速度估计毛刺 | 检查 PLL 锁定状态 |
| 欠压/过压 | 电源波动 | 加大 `PROT_VBUS_MS` 去抖 |
| 编码器 | 排线接触不良 | 检查接线 |

**恢复流程**：`stop` → 排除原因 → `start`。FAULT 状态下 `start` 会被拒绝。

---

## 8. 串口通信问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 命令无回复 / 回复错乱 | **`wave on` 占满带宽**（19 ch × 500 Hz = 47.5 kB/s） | 先 `wave off` |
| 波特率不对 | — | 1000000 8N1 |
| `rx_drop` 增长 | 主机发送过快 | 加延时 |
| 回复被截断 | TX 环形缓冲满 | `stat` 看 `tx_pending`/`tx_stuck` |

> **自动化测试铁律**：脚本第一步必须 `wave off`。

---

## 9. 编译与烧录

| 现象 | 原因 | 处理 |
|---|---|---|
| 改结构体后行为异常 | 增量编译未更新依赖 | 用 **Rebuild（-r）** 而非 Build（-b） |
| `UV4 -f` 失败（exit 2） | 串口/DAPLink 被占用 | 关闭终端或 VOFA+ |
| Keil 打不开工程 | 工程文件被改动 | 从 git 恢复 |

---

## 10. 已知限制（非故障）

| 项 | 表现 | 原因 |
|---|---|---|
| 30 rpm 以下脉动大 | ±18% | 齿槽力矩与摩擦同量级 |
| 高速脉动 ~0.5% | 5~11 rpm | 测速分辨率与齿槽 |
| 标 2000 只到 ~1900 | m=0.95 | 12 V 母线下的电压上限 |
| `wave on` 时 CRC 错误率升高 | ~3e-5 | 线缆 EMI，坏帧被丢弃不影响控制 |
| 阶跃响应 rise 100~1200 ms | — | 参考斜坡（600 rpm/s）限制，属设计行为 |
