### PLL 观测器（S8.1）

| 宏 | 值 | 说明 |
|---|---|---|
| `PLL_WN_HZ` ⚙️ | **14.0** | 自然频率；实测最优 12~16 Hz |
| `PLL_ZETA` ⚙️ | 0.707 | 阻尼比 |

> 带宽扫描结论：8 Hz → 纹波大（跟踪慢）；**14 Hz → 最优**；≥40 Hz → 齿槽/电频率进入反馈。

### 速度环的整定依据

| 参数 | 依据 |
|---|---|
| `SPD_KP 0.006` | 再大到 0.016 就失稳（PLL 14 Hz 带来约 11 ms 延迟） |
| `SPD_KI 0.080` | 再大则阶跃超调增大；稳态误差靠积分消除 |
| `SPD_FF_ACC` | 缺它时 100 rpm 阶跃超调 96%，加上后 8% |
| `SPD_RAMP_RPM_S 600` | 与加速度前馈配合；太快则电流饱和 |
| `SPD_LPF_*` | 抑制 10 ms 窗口测速的台阶（PLL 默认源下仍保留） |

## 10. 硬件能力边界（重要）

| 项 | 数值 | 说明 |
|---|---|---|
| 母线电压 | 12 V（实测 11.94） | 决定最高转速 |
| 反电动势 | 4.13 mV/(电 rad/s) | 1500 rpm → 4.54 V；2000 rpm → 6.06 V |
| 电压上限 | 5.7 V（0.5×Vdc×0.95） | **2000 rpm 物理不可达** |
| 实测最高转速 | 约 **1900 rpm**（m 饱和在 0.95） | 建议长期运行 ≤1800 rpm |
| 电流量程 | ±1.32 A（ADC） | 决定了过流阈值上限 1.30 A |
| 最低可用转速 | 约 **30 rpm**（脉动 ±18%） | 齿槽力矩与摩擦同量级 |

## 11. 运行时命令对应的参数

| 命令 | 修改的宏 |
|---|---|
| `pi <kp> <ki>` | `FOC_KP` / `FOC_KI` |
| `spi <kp> <ki>` | `SPD_KP` / `SPD_KI` |
| `sff <base> <slope>` | `SPD_FF_BASE` / `SPD_FF_SLOPE` |
| `ff <0..1>` | `FOC_FF_GAIN` |
| `pll wn/zeta` | `PLL_WN_HZ` / `PLL_ZETA` |
| `prot oc/os/st/siq/uv/ov` | 对应 `PROT_*` / `VBUS_*_V` |
| `rate <hz>` | `DBG_WAVE_RATE_HZ` |

> 以上全部为**运行时 RAM 修改**，重新上电或烧录恢复为 `board_cfg.h` 的默认值。
