# 30 · 命令手册

> 适用固件：**#127** 及以后 · 串口 **1000000 8N1**（`ver` 可确认版本）
> 所有命令以 CRLF 结尾，回复以 `[log] ` 前缀输出。

## 0. 快速上手

```
mode 2          # 选择 FOC 模式
start           # 使能桥臂
spd 500         # 速度环 500 rpm（内部按 600 rpm/s 斜坡逼近）
spd             # 查看参考 / 实测 / iq
spd off         # 释放速度环，回到电流模式
stop            # 关桥臂
```

## 1. 基本信息

| 命令 | 作用 | 示例 |

---

## 2. 运行控制

| 命令 | 作用 | 说明 |
|---|---|---|
| `start` | 使能桥臂（MOE=1） | 必须先 `mode` 选好模式 |
| `stop` | 关闭桥臂并回到 IDLE | FAULT 状态下用它清除故障 |
| `mode <0\|1\|2>` | `0`=IDLE `1`=OPENLOOP（V/f） `2`=FOC | 切换前必须先 `stop` |

**典型顺序**：`stop` → `mode 2` → `start` → 操作 → `stop`

## 3. 开环模式（mode 1）

| 命令 | 作用 | 范围 |
|---|---|---|
| `vf <hz>` | V/f 频率目标（电频率） | 1 ~ 400 Hz |
| `vf off` / `vf 0` | 停止调制，回到 50% 零矢量 | — |
| `acc <hz/s>` | 频率斜坡速率 | 1 ~ 200 Hz/s |
| `dir <0\|1>` | 相序；`1` 反转 | — |
| `pwm <d>` / `pwm <a> <b> <c>` | 固定占空比 | 0 ~ 1 |

## 4. 电流环（mode 2）

| 命令 | 作用 | 范围 / 说明 |
|---|---|---|
| `id <A>` | d 轴电流参考 | ±1.2 A |
| `iq <A>` | q 轴电流参考 | ±1.2 A，**速度环开启时会被拒绝** |
| `foc` | 显示 id/iq、参考、vd/vq、调制比、故障计数 | — |
| `pi` | 显示电流环 PI 增益 | — |
| `pi <kp> <ki>` | 设置电流环 PI（运行时，不写 flash） | kp 0.05~20，ki 0~50000 |
| `step <A>` | 20 kHz 采样的电流阶跃测量，输出 rise/超调/误差 | 0.05 ~ 1.2 A |
| `ff <0..1>` | 反电动势+解耦前馈增益 | 0 关闭，1 全量 |
| `cur` | 三相原始码、电流、ADC 状态 | — |

## 5. 速度环（mode 2 + `spd`）

| 命令 | 作用 | 范围 / 说明 |
|---|---|---|
| `spd <rpm>` | 速度目标（内部按斜坡逼近） | ±2000，实际可达约 1800 |
| `spd off` | 释放速度环，`iq` 归零 | — |
| `spi` | 显示速度 PI 增益 | — |
| `spi <kp> <ki>` | 设置速度 PI（运行时） | kp 0~5，ki 0~50 |
| `sstep <rpm>` | 1 kHz 采样的速度阶跃测量：rise / 超调 / 误差 / 稳定时间 | 50 ~ 2000 rpm |
| `sff` / `sff <base> <slope>` | 摩擦前馈：基值 A + 斜率 A/1000rpm | base 0~0.5，slope 0~0.5 |
| `rip` | 最近 500 ms 的 iq 与转速峰峰值（1 kHz 采样） | 需先运行 0.5 s 以上 |
| `pll` | 显示测速源、PLL 带宽/阻尼、锁定状态、两种测速对比 | — |
| `pll on` / `pll off` | 测速源：PLL 观测器 / 10 ms 窗口 | 默认 PLL |
| `pll wn <hz>` | PLL 自然频率 | 10 ~ 400 Hz，推荐 **14** |
| `pll zeta <v>` | PLL 阻尼比 | 0.3 ~ 2.0，推荐 0.707 |

### 速度环工作要点

- 参考有 **600 rpm/s 的加速度限制**（`SPD_RAMP_RPM_S`）
- 起转时施加 0.20 A 的 kick，持续 250 ms 且仅在转子接近静止时
- 高速段反馈经低通滤波（车速相关，`SPD_LPF_*`）

## 6. 编码器与对齐

| 命令 | 作用 | 说明 |
|---|---|---|
| `enc` | 机械角/电角度/转速/CRC 统计/零位/方向 | — |
| `enc zero` | 把当前角度记为零位并写 flash | 上电自动加载 |
| `enc dir <0\|1>` | 设置旋转方向 | — |
| `enc raw` | 显示原始帧与磁场状态 | — |
| `align` | 双向扫频对齐转子并写入电角度零位（需要编码器测量） | 有感调试 |
| `align ol` | **开环预定位**：固定矢量 500 ms 把转子拉到 theta=0，**不需要编码器** | 无感 / 换电机 |
| `obs` | 无感观测器（影子模式）：`on`/`off`、`bw <hz>`、`r <ohm>`、`l <mH>`；不带参数时显示 `eα/eβ/ed/eq/θ̂/ω̂` 与编码器角度差 | S10.1 |
| `if` | **S10.4 开环 I/f 启动**：`if <rpm>` 从 0 起转、`if off` 停止；不带参数显示当前频率/幅值/角度 | 无编码器启机 |

## 8. 保护（S7.6）

| 命令 | 作用 |
|---|---|
| `fault` | 最近一次故障（类型/数值/时刻）+ 六类累计计数 |
| `prot` | 显示全部阈值 |
| `prot oc <A>` | 过流跳闸阈值 **0.20 ~ 1.30 A** |
| `prot os <rpm>` | 超速阈值 **100 ~ 6000 rpm** |
| `prot st <rpm>` | 堵转转速门限 **1 ~ 1000 rpm** |
| `prot siq <A>` | 堵转电流门限 **0.05 ~ 1.2 A** |
| `prot uv <V>` | 欠压阈值 **5 ~ 20 V** |
| `prot ov <V>` | 过压阈值 **5 ~ 24 V** |

### 六类保护

| 保护 | 默认判据 | 动作 |
|---|---|---|
| 过流 | 任一相 ≥ 1.28 A，5 帧 | 关桥臂 + FAULT |
| 超速 | \|spd\| > 2000 rpm，100 ms | 同上 |
| 堵转 | \|spd\| < 30 rpm 且 \|iq\| > 0.6 A，500 ms（仅速度环） | 同上 |
| 欠压 | Vbus < 9.0 V，50 ms | 同上 |
| 过压 | Vbus > 13.8 V，50 ms | 同上 |
| 编码器 | 20 帧无新有效帧，或 200 帧 raw 恒 0 | 同上 |

`start` 后 **200 ms 宽限期**内不判定速度/电压类保护。

## 9. 波形与调试

| 命令 | 作用 | 说明 |
|---|---|---|
| `wave on` / `wave off` | VOFA+ FireWater 波形上传 | **开启会占用大量串口带宽** |
| `rate <hz>` | 波形速率 | 1 ~ 500 Hz |
| `prof [reset\|on\|off]` | 分段耗时统计（ISR/ADC/编码器/控制环） | — |
| `phase [reset]` | 每个阶段落在 50 µs PWM 周期内的位置 | — |
| `trig` | sin/cos 后端基准测试 | — |
| `cordic` | CORDIC 原始回读 | 实验用 |
| `led <on\|off\|toggle>` | PF1 LED | — |

### 波形通道（19 路，FireWater 格式）

| 通道 | 内容 | 单位 | 换算 |
|---|---|---|---|
| 0 | 时间 | ms | — |
| 1~3 | 三相占空比 | — | — |
| 4~6 | 三相电流 | A | — |
| 7 | 机械角 | ° | — |
| 8 | 电角度 | ° | — |
| **9** | **电频率** | **Hz** | `rpm = ch9 × 60 / 7` |
| 10 / 11 | id / iq | A | — |
| 12 / 13 | id_ref / iq_ref | A | — |
| 14 / 15 | vd / vq | V | — |
| 16 | 母线电压 | V | — |
| 17 | **窗口测速** | rpm | 与 ch9 对比用 |
| 18 | **PLL 测速** | rpm | 与 ch9 对比用 |

> ⚠️ **`wave on` 时不要跑自动化测试**：19 通道 × 500 Hz = 47.5 kB/s，
> 会占满 1 Mbaud 链路，导致命令回复延迟、读数错乱。

## 10. 常见误区

| 现象 | 原因 | 解决 |
|---|---|---|
| `iq` 命令无效 | 速度环持有 iq 参考 | 先 `spd off` |
| `spd` 命令报错 | 未 `start` 或不是 FOC 模式 | `mode 2` + `start` |
| 设了 2000 rpm 但只到约 1900 | 12 V 供电下的电压上限 | 属于物理限制，见 docs/21 |
| 波形读数与实际情况不符 | `wave on` 占满串口 | `wave off` 后再测 |

### 波形通道表（`wave on`，FireWater 格式，21 通道）

| 通道 | 含义 | 单位 | 备注 |
|---|---|---|---|
| 0 | 上电时间 | s | 横轴用 |
| 1 | A 相占空比 | 0~1 | |
| 2 | B 相占空比 | 0~1 | |
| 3 | C 相占空比 | 0~1 | |
| 4 | ia | A | 相电流（三电阻采样） |
| 5 | ib | A | |
| 6 | ic | A | |
| 7 | 机械角 | ° | 仅编码器；`enc off` 时为旧值 |
| 8 | 电角度 | ° | **控制器实际使用的角度**（见下表） |
| 9 | 转速 | **电频率 Hz** | **控制器实际使用的转速**（见下表） |
| 10 | id 实测 | A | |
| 11 | iq 实测 | A | |
| 12 | id 指令 | A | |
| 13 | iq 指令 | A | 速度环输出 |
| 14 | vd | V | |
| 15 | vq | V | |
| 16 | 母线电压 | V | |
| 17 | 窗口估计转速 | rpm | 编码器路径 |
| 18 | PLL 观测器转速 | rpm | 编码器路径（S8.1） |
| 19 | 观测器电角度 | ° | **无感观测器**（S10.1） |
| 20 | 观测器 − 编码器角度差 | ° | 关键指标：稳定为小值说明观测器可信 |


**ch8 / ch9 随模式自动切换（#161）**：

| 当前模式 | ch8 电角度 | ch9 电频率 |
|---|---|---|
| 有感（编码器启用） | 编码器 | 编码器 |
| I/f 开环拖动 | 强制坐标系 | 拖动指令频率 |
| **无感闭环** | **观测器** | **观测器** |
| `enc off` 且未运行 | 0 | 0 |

> 所以无编码器时 **I9 依然是有效的**，它就是观测器的电频率；
> 换算转速：`rpm = I9 × 60 / 7 = I9 × 8.571`。
> 想看 rpm 可直接用文本命令 `spd`（`meas` 字段）或 `sfoc`（`obs w`）。
>
> ch17/ch18（编码器窗口/PLL 转速）在 `enc off` 后恒为 0，**不要看**。

> ⚠️ **无编码器（`enc off`）时**：ch7/8/9 停在旧值、ch17/18 为 0、
> **ch20 无意义**（拿观测器和一个失效的编码器比）。
> 此时看 **ch19（观测器角度）+ ch13/ch11（iq 指令/实测）+ ch15（vq）**。

> ⚠️ **通道 9 是电频率 Hz，不是 rpm**。直接和 ch17/18 画在一起会差 8.57 倍
> （7 对极：rpm = Hz × 60/7）。

> 发送速率：`wave rate <Hz>`，上限 `DBG_WAVE_RATE_MAX`（500 Hz）。
> 21 通道 × 5 字节 = 105 字节/帧，115200 波特率下最高约 100 Hz，
> 1 Mbps 下才能跑满 500 Hz。
