# 30 · 命令手册

> 适用固件：**#127** 及以后 · 串口 **1000000 8N1**（`ver` 可确认版本）
> 所有命令以 CRLF 结尾，回复以 `[log] ` 前缀输出。

## 0. 快速上手

```
mode 2          # 选择 FOC 模式
start           # 使能桥臂
spd 500         # 速度环 500 rpm（内部按 600 rpm/s 斜坡逼近）
spd             # 查看参考 / 实测 / iq
spd off         # 释放速度环，回到电流模式
stop            # 关桥臂
```

## 2. 运行控制

| 命令 | 作用 | 说明 |
|---|---|---|
| `start` | 使能桥臂（MOE=1） | 必须先 `mode` 选好模式 |
| `stop` | 关闭桥臂并回到 IDLE | FAULT 状态下用它清除故障 |
| `mode <0\|1\|2>` | `0`=IDLE `1`=OPENLOOP（V/f） `2`=FOC | 切换前必须先 `stop` |

**典型顺序**：`stop` → `mode 2` → `start` → 操作 → `stop`

## 4. 电流环（mode 2）

| 命令 | 作用 | 范围 / 说明 |
|---|---|---|
| `id <A>` | d 轴电流参考 | ±1.2 A |
| `iq <A>` | q 轴电流参考 | ±1.2 A，**速度环开启时会被拒绝** |
| `foc` | 显示 id/iq、参考、vd/vq、调制比、故障计数 | — |
| `pi` | 显示电流环 PI 增益 | — |
| `pi <kp> <ki>` | 设置电流环 PI（运行时，不写 flash） | kp 0.05~20，ki 0~50000 |
| `step <A>` | 20 kHz 采样的电流阶跃测量，输出 rise/超调/误差 | 0.05 ~ 1.2 A |
| `ff <0..1>` | 反电动势+解耦前馈增益 | 0 关闭，1 全量 |
| `cur` | 三相原始码、电流、ADC 状态 | — |
| `cal` | 重新标定电流零偏：先把三相拉到 0.50（不产生相间电压），连续采 `CUR_CAL_SAMPLES` 帧取平均并写 flash；要求 `state = RUN`（否则 `ERR start first`，因为 ADC 注入需要 MOE=1） | 约 256 帧 ~ 13 ms |
| `cal erase` | 清掉已存的零偏，下次 `start` 时重新标定（运行中会先拉零矢量，避免把负载电流平均进去） | — |

## 5. 速度环（mode 2 + `spd`）

| 命令 | 作用 | 范围 / 说明 |
|---|---|---|
| `spd <rpm>` | 速度目标（内部按斜坡逼近），回复标注 `(encoder)`/`(observer)` | ±2000，实际可达约 1800 |
| `spd off` / `spd 0` | 释放速度环，`iq` 归零。**不会**退出无感（`s_sfoc` 仍为 1），转子还在转时可直接用 `spd <rpm>` 接回；停稳后再起转需 `sfoc off` → `sfoc go` | — |
| `sident [r / ke / l / hf / all / stop]` | 辨识 R / KE / L；`hf` 用 2 kHz 注入测 L（推荐，实测 0.50 mH 与手册一致），`l` 是阶跃法、标记 experimental；打印 `motor_cfg.h` 建议整数。要求 `mode 2` + `start`、母线 < 13 V、转子静止（`ERR rotor still turning` / `ERR bus ... V`）；KE 段结束后自动刹车到停 | 约 4 s |
| `spi` | 显示速度 PI 增益 | — |
| `spi <kp> <ki>` | 设置速度 PI（运行时） | kp 0~5，ki 0~50 |
| `sstep <rpm>` | 1 kHz 采样的速度阶跃测量：rise / 超调 / 误差 / 稳定时间 | 50 ~ 2000 rpm |
| `sff` / `sff <base> <slope>` | 摩擦前馈：基值 A + 斜率 A/1000rpm | base 0~0.5，slope 0~0.5 |
| `rip` | 最近 500 ms 的 iq 与转速峰峰值（1 kHz 采样） | 需先运行 0.5 s 以上 |
| `pll` | 显示测速源、PLL 带宽/阻尼、锁定状态、两种测速对比 | — |
| `pll on` / `pll off` | 测速源：PLL 观测器 / 10 ms 窗口 | 默认 PLL |
| `pll wn <hz>` | PLL 自然频率 | 10 ~ 400 Hz，推荐 **14** |
| `pll zeta <v>` | PLL 阻尼比 | 0.3 ~ 2.0，推荐 0.707 |

### 速度环工作要点

- 参考有 **600 rpm/s 的加速度限制**（`SPD_RAMP_RPM_S`）
- 起转时施加 0.20 A 的 kick，持续 250 ms 且仅在转子接近静止时
- 高速段反馈经低通滤波（车速相关，`SPD_LPF_*`）

## 8. 保护（S7.6）

| 命令 | 作用 |
|---|---|
| `fault` | 最近一次故障（类型/数值/时刻）+ 六类累计计数 |
| `prot` | 显示全部阈值 |
| `prot oc <A>` | 过流跳闸阈值 **0.20 ~ 1.30 A** |
| `prot os <rpm>` | 超速阈值 **100 ~ 6000 rpm** |
| `prot st <rpm>` | 堵转转速门限 **1 ~ 1000 rpm** |
| `prot siq <A>` | 堵转电流门限 **0.05 ~ 1.2 A** |
| `prot uv <V>` | 欠压阈值 **5 ~ 20 V** |
| `prot ov <V>` | 过压阈值 **5 ~ 24 V** |

### 六类保护

| 保护 | 默认判据 | 动作 |
|---|---|---|
| 过流 | 任一相 ≥ 1.28 A，5 帧 | 关桥臂 + FAULT |
| 超速 | \|spd\| > 2000 rpm，100 ms | 同上 |
| 堵转 | \|spd\| < 30 rpm 且 \|iq\| > 0.6 A，500 ms（仅速度环） | 同上 |
| 欠压 | Vbus < 9.0 V，50 ms | 同上 |
| 过压 | Vbus > 13.8 V，50 ms | 同上 |
| 编码器 | 20 帧无新有效帧，或 200 帧 raw 恒 0 | 同上 |

`start` 后 **200 ms 宽限期**内不判定速度/电压类保护。

## 9. 波形与调试

| 命令 | 作用 | 说明 |
|---|---|---|
| `wave on [hz]` / `wave off` | VOFA+ 波形上传，可顺带设速率 | 21 通道用 `wave on 250`；500 Hz 实测会溢出（#167） |
| `rate <hz>` | 波形速率 | 1 ~ 500 Hz |
| `prof [reset\|on\|off]` | 分段耗时统计（ISR/ADC/编码器/控制环） | — |
| `phase [reset]` | 每个阶段落在 50 µs PWM 周期内的位置 | — |
| `trig` | sin/cos 后端基准测试 | — |
| `cordic` | CORDIC 原始回读 | 实验用 |
| `led <on\|off\|toggle>` | PF1 LED | — |

> 通道含义见文末「波形通道表（`wave on`，ASCII CSV，21 通道）」。
> ⚠️ **`wave on` 时不要跑自动化测试**：21 通道 × 500 Hz ≈ 68.5 kB/s
> （685 kbps），会占满 1 Mbaud 链路，命令回复延迟、读数错乱；
> 抓波形用 `wave on 250`（见 #167）。

## 10. 常见误区

| 现象 | 原因 | 解决 |
|---|---|---|
| `iq` 命令无效 | 速度环持有 iq 参考 | 先 `spd off` |
| `spd` 命令报错 | 未 `start` 或不是 FOC 模式 | `mode 2` + `start` |
| `ERR no encoder: use ...` | 编码器被 `enc off`，有感速度环没有反馈 | 接编码器后 `enc on`，或改用 `sfoc go <rpm>` |
| `ERR I/f running, wait for hand-over` | I/f 起转/交接期间 `idq` 被强制坐标系覆盖 | 等 `sensorless 1`，或直接用 `sfoc go` 改目标 |
| 反向 `sfoc go -400` 后转速卡住不动、`iq_ref` 饱和 | #169 及更早：前馈在 PI 限幅之后加，反向净电压只剩 2.8 V | 升级到 **#170**，反向也能正常闭环 |
| 设了 2000 rpm 但只到约 1900 | 12 V 供电下的电压上限 | 属于物理限制，见 docs/21 |
| 波形读数与实际情况不符 | `wave on` 占满串口 | `wave off` 后再测 |

### 波形通道表（`wave on`，ASCII CSV，21 通道）

> 格式：每帧一行、逗号分隔、`\n` 结尾；VOFA+ 选 **FireWater → CSV**
> （固件实际发的是 ASCII CSV，不是二进制 justfloat）。
> 带宽：实测 137 B/帧 → 500 Hz 是 685 kbps（1 Mbaud 的 69%，会溢出），
> 250 Hz 是 342 kbps（推荐）。#167 起可用 `wave on 250` 一次设好。

| 通道 | 含义 | 单位 | 数据源 |
|---|---|---|---|
| 0 | 上电时间 | s | `HAL_GetTick()` |
| 1 | A 相占空比 | 0~1 | PWM 寄存器回读 |
| 2 | B 相占空比 | 0~1 | 同上 |
| 3 | C 相占空比 | 0~1 | 同上 |
| 4 | ia | A | 三电阻采样 |
| 5 | ib | A | |
| 6 | ic | A | |
| 7 | 机械角 | ° | **仅编码器**（`enc off` 时停在旧值） |
| 8 | 电角度 | ° | 编码器优先，缺失时用控制器实际源（见下） |
| 9 | 转速 | **电频率 Hz** ⚠️ | 同 ch8 的源；**rpm = ch9 × 60/7** |
| 10 | id 实测 | A | |
| 11 | iq 实测 | A | |
| 12 | id 指令 | A | |
| 13 | iq 指令 | A | 速度环/力矩指令输出 |
| 14 | vd | V | |
| 15 | vq | V | |
| 16 | 母线电压 | V | ADC 分压 |
| 17 | 编码器窗口估计转速 | rpm | **仅编码器**（`enc off` → 0） |
| 18 | 编码器 PLL 转速 | rpm | **仅编码器**（`enc off` → 0） |
| 19 | 观测器电角度 | ° | **无感观测器**（一直有效） |
| 20 | 观测器 − 编码器角度差 | ° | **仅编码器**（`enc off` 时无意义） |

#### ch8 / ch9 的数据源（#162）

| 场景 | ch8 电角度 | ch9 电频率 |
|---|---|---|
| 有编码器（无论有感/无感） | 编码器 | 编码器 |
| 无编码器 + 无感 | 观测器 | 观测器 |
| 无编码器 + I/f 拖动 | 强制坐标系 | 拖动指令频率 |
| 无编码器 + 未运行 | 0 | 0 |

> **有编码器时 ch8 保持"编码器原始角度"**，这样 ch19（观测器角度）和
> ch20（两者差值）才有对照基准；编码器缺失时才回退，避免通道变死。

#### 无编码器（`enc off`）时该看什么

| 关注点 | 看这些通道 | 不要看 |
|---|---|---|
| 转速 | **ch9**（×8.571 转 rpm） | ch17、ch18 |
| 角度 | ch8 或 ch19（两者相同） | ch20 |
| 电流跟踪 | ch13 vs ch11 | — |
| 电压 | ch14/ch15 | — |
