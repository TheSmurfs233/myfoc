# 子框架 · ADC 三相电流采样

---

## 1. 职责边界

- **管**：三相电流的硬件链路、ADC 触发时序、原始码值 → 安培的换算、零点校准、采样质量诊断。
- **不管**：电流环 PI、过流保护动作（分别见 16、17 号文档）。

## 2. 接口

```c
/* User/Mid/mid_current.h */
typedef struct {
    float    ia, ib, ic;     /* 安培，已扣零漂、已乘极性 */
    uint16_t raw[3];         /* 原始码值（调试用） */
    uint16_t offset[3];      /* 零漂码值（校准得到） */
    uint8_t  ready;          /* 1 = offset 有效 */
    uint8_t  saturated;      /* 1 = 有通道贴边 */
    uint8_t  src;            /* offset 来源：0=名义值 1=Flash 2=本次校准 */
    uint32_t frames;         /* 已处理帧数 */
} current_sample_t;

void  mid_current_init(void);                    /* offset=2048，开始校准 */
void  mid_current_restart_cal(void);             /* 重新校准（桥臂必须关断） */
void  mid_current_update(const uint16_t raw[3]); /* 主循环内每帧调用一次 */
const current_sample_t *mid_current_get(void);

/* User/Bsp/bsp_adc.h —— 只做硬件层，不做换算、不打日志 */
void     bsp_adc_init(void);        /* ADC 校准 + 启动注入组（中断方式） */
uint8_t  bsp_adc_started(void);
uint32_t bsp_adc_frames(void);      /* 已完成帧数（20kHz） */
uint32_t bsp_adc_ovr_count(void);   /* 溢出次数 */
void     bsp_adc_get_raw(uint16_t raw[3]);
```

**分工**：`bsp_adc` 的 JEOC 回调只做"读 3 个 JDR + 计数 + 打点"，换算在 `mid_current`
（主循环消费），这样 S3 阶段 ISR 极短、好定位；S6 会把换算+FOC 整体搬进 ISR。

### 2.1 校准与 Flash 持久化（#24 起）

```
上电 ──► mid_current_load()
           ├─ 有效记录 ──► offsets 直接恢复，ready=1，start 不再校准
           └─ 无记录 ────► ready=0
                            └─ 第一次 start（50% 零矢量）→ 采 256 帧 → 写 Flash → ready=1
```

| 项 | 值/行为 |
|---|---|
| 存储位置 | **最后一页 2KB**：`0x0801F800`（Keil 目标 ROM 已缩到 `0x1F800`，链接器不会占用） |
| 记录格式 | `magic('CAL1') + version + offset[3] + CRC16-CCITT`，共 16 字节 |
| 写入时机 | 校准完成的**那一帧**（`mid_current_update` 内），此时桥臂处于 50% 零矢量 |
| 写入代价 | 单 bank G4 擦/写时 CPU 停 ~20-40ms；PWM 与驱动由硬件继续，用户无感 |
| 失效处理 | magic/version/CRC 任一不符 → 视为未校准（掉电写坏也安全） |
| 清除 | `cal erase` 命令（擦掉记录并回到未校准状态） |

> 为什么不用后备电池/RTC：采样电阻和 INA240 的零漂是**静态误差**，掉电不会变，
> 存一次即可；温度漂移靠 `cal` 手动重做。

## 3. 关键参数

### 3.1 硬件链路

```
U 半桥中点 ──┬── R1 25mΩ ──┬── U（到电机）
             │             │
          IU-(IN-)       IU+(IN+)           INA240A2 (U6)  增益 50V/V
                              ├─ REF1=AGND, REF2=A3V3 → VREF=1.65V
                              └─ OUT ─ R18 10Ω ─ ISU ─→ PA4 (ADC2_IN17, JDR1)

V 相半桥中点 ── R2 25mΩ ── V ── INA240 (U2) ─ ISV ─→ PA5 (ADC2_IN13, JDR2)
W 相半桥中点 ── R3 25mΩ ── W ── INA240 (U3) ─ ISW ─→ PA6 (ADC2_IN3,  JDR3)
```

> **2026-10-25 更正**：采样电阻**串在相线里（inline）**，不是低侧源极到 PGND。
> 相电流在开关周期内连续流过 R1，**任何时刻都能采**——采样时刻只影响噪声，不影响可测性。

| 项 | 值 | 备注 |
|---|---|---|
| ADC | ADC2，12bit，单端 | adc.c |
| ADC 时钟 | SYSCLK/4 = 42.5MHz | adc.c |
| 采样时间 | 24.5 cycles（注入组） | adc.c |
| 单通道转换 | (24.5 + 12.5)/42.5MHz = **0.871 µs** | 计算 |
| 3 通道总耗时 | **2.61 µs** | 计算 |
| 触发源 | `TIM1_CC4` 上升沿（`ADC_EXTERNALTRIGINJEC_T1_CC4`） | adc.c |
| 中断 | `ADC1_2_IRQn`（JEOC），优先级需改 0 | it.c |
| INA240 增益 | **50 V/V**（A2 型号） | 硬件 |
| 参考电压 | 3.3V（VDDA=VREF+，无外部基准） | 原理图 |
| 采样电阻 | **25 mΩ**（实际焊接，原理图标 10mΩ） | 实测/用户确认 |
| INA240 偏置 | REF1=AGND, REF2=A3V3 → **VREF=1.65V** | 原理图核对 |

### 3.2 采样时刻：选在三角波峰顶（PWM 周期中心）

因为是**相线串联**采样，`i_phase` 在整个开关周期内连续流过 R1，所以**任何时刻都能采到真实相电流**。
采样时刻的选择只剩一个考虑：**离开关沿越远越安静**。

中心对齐 PWM 下，一个周期有两次换相，分别在峰顶和谷底附近：

- **峰顶（CNT=ARR，周期中心，25µs）**：PWM2 下三相上管全开，但电流仍流过 R1（inline 特性），
  且此处是**高电平脉冲的中心**，距离该相的两侧开关沿各 `duty × 25µs`；
- **谷底（CNT=0，周期边界）**：同理，距离两侧开关沿各 `(1−duty) × 25µs`。

两者都可用。本项目选**峰顶**：它同时是"平均电流"的采样点，且在高占空比（大电流）时窗口更宽。

CC4 怎么产生上升沿：`CH4` 配 **PWM2**，`CCR4` **由 CubeMX 的 CH4 Pulse 决定**（当前 4000，固件不覆盖）。
PWM2 下 `CNT ≥ CCR4` 时输出高，所以每个周期在 **CNT=4000（峰顶前约 1.5µs）** 产生一个
**约 2.9µs 宽的高脉冲**，其**上升沿**触发注入组。

> 为什么不用 `CCR4 = ARR`（正好峰顶）：那样脉宽只有 1 个计数（≈6ns），示波器上根本看不见，
> 调试时无法确认触发位置。当前值提前 1.5µs（周期的 3%），电流只差纹波的一小部分。
> 这个值是 CubeMX 配置项，想改直接改 CubeMX 的 Pulse，**固件不会覆盖**。

> 残余限制（S3 处理）：占空比很低的那一相，其开关沿会靠近峰顶。
> 若某相 `duty < 2.61µs/50µs ≈ 5.2%`，它的沿会落进 ADC 转换窗口内。
> SVPWM 满调制时最低相占空比约 6.7%，处于临界——S3 实测后决定是否需要
> 缩短 ADC 采样时间（24.5→12.5 周期）或把触发点微移。

### 3.3 码值 → 安培换算

```
V_adc   = raw × 3.3V / 4096                     (0.806 mV/LSB)
V_sense = (V_adc − V_ref) / 50                  (INA240A2 增益 50)
I_phase = V_sense / R_shunt
```

合并：

```
I = (raw − raw_offset) × (3.3 / 4096) / 50 / R_shunt
  = (raw − raw_offset) × K
```

| Rshunt | K（A/LSB） | 双向量程 | 说明 |
|---|---|---|---|
| 10 mΩ | 1.61 mA | ±3.3 A | 原理图标注值（实物不是这个） |
| **25 mΩ（本项目）** | **0.645 mA** | **±1.32 A** | 实际焊接值，代码按此配置 |

灵敏度 = Rshunt × 50 = **1.25 V/A**；
量程 = 1.65V（VREF）÷ 1.25V/A = **±1.32 A**；
分辨率 = 0.806mV ÷ 1.25V/A = **0.645 mA/LSB**。

⚠ **±1.32A 很小**。若电机额定电流 >1A，S3 标定时会看到 ADC 贴边（码值 0 或 4095，切顶），
届时只能换更小阻值的采样电阻（10mΩ → ±3.3A，5mΩ → ±6.6A）。

**已确认（2026-10-25 核对原理图）**：INA240 的 `REF1 = AGND`、`REF2 = A3V3`，
所以 `VREF = (0 + 3.3)/2 = 1.65V`，是标准的**双向**偏置：

- 零电流 → 1.65V → 码值 **2048**
- 正电流 → 码值上升，负电流 → 码值下降，**正负都能测**
- 满量程 ±1.32A（受 1.65V / 1.25V·A⁻¹ 限制）

代码里对应 `board_cfg.h`：

```c
#define RSHUNT_OHM    0.025f
#define INA240_GAIN   50.0f
#define CUR_A_PER_LSB ((ADC_VREF / ADC_FULL_SCALE) / (INA240_GAIN * RSHUNT_OHM))  /* 0.645mA */
#define CUR_ZERO_CODE (ADC_FULL_SCALE * 0.5f)                                     /* 2048 */
#define CUR_RANGE_A   ((ADC_VREF * 0.5f) / (INA240_GAIN * RSHUNT_OHM))            /* ±1.32A */
```

## 4. 时序/数据流

```
TIM1 CNT 峰顶（CNT=ARR）
    │
    ├─ CC4 上升沿 ──▶ ADC2 注入组启动（硬件，无需 CPU）
    │                     │
    │                     ├ rank1: PA4 → JDR1   0.871us
    │                     ├ rank2: PA5 → JDR2   0.871us
    │                     └ rank3: PA6 → JDR3   0.871us
    │                                    │
    │                          JEOC ─────┘ (t = 2.61us)
    │                                    ▼
    │                          ADC1_2_IRQHandler
    │                                    ▼
    │                          HAL_ADCEx_InjectedConvCpltCallback(&hadc2)
    │                                    ▼
    │                          mid_current_update(JDR1, JDR2, JDR3)
    │                                    ▼
    └──────────────────────────  foc_core_step()
```

**读 JDR 必须直读寄存器**，不要用 `HAL_ADCEx_InjectedGetValue()`（函数调用+多次判断，多花几百 ns）：

```c
uint16_t j1 = (uint16_t)hadc2.Instance->JDR1;
uint16_t j2 = (uint16_t)hadc2.Instance->JDR2;
uint16_t j3 = (uint16_t)hadc2.Instance->JDR3;
```

## 6. 验证方法（S3 台架清单）

**前置**：采样电阻串在相线上，**空载时电流恒为 0**，必须接负载才能验证极性和增益。

> **校准时机（2026-10-25 实测确认）**：TIM1_CC4 的触发**被 MOE 门控**——桥臂关断时
> ADC 一次都不会转换。所以零漂校准不能在"上电、MOE=0"时做，而是**在 `start` 时自动做**：
> 桥臂以 50% 零矢量使能（相间无电压、无电流），采 256 帧（12.8ms）后 `cal` 变 1。
> 校准期间 `pwm` 命令返回 `ERR calibrating`。

| # | 测试 | 方法 | 判据 |
|---|---|---|---|
| 1 | 零漂 | **`mode 1`+`start` 后**（校准自动完成）`cur` | raw = **2048 ± 20**（三相） |
| 2 | 噪声 | `mode 1` + `start`，`pwm 0.5`（零矢量，无电流） | raw 抖动 **< ±8 LSB** |
| 3 | 帧率 | `stat` 看 `frames` 增速 | **≈20 000 帧/s** |
| 4 | 溢出 | `stat` 的 `ovr` | **0** |
| 5 | 极性/增益 | 相间负载（见下） | 读数与欧姆定律一致，符号符合约定 |
| 6 | 线性 | 两个电流点（如 100mA / 300mA） | 误差 <3% |
| 7 | 饱和 | 电流逼近 ±1.3A | `sat=1`，不崩 |

### 6.1 负载接法（二选一）

**A. 单相到地**（最简单）

```
U 端子 ── 47Ω/5W ── GND
pwm 0.5   → 峰顶 U=12V → I ≈ 255mA → raw ≈ 2048 + 395 ≈ 2443
```

**B. 相间**（能同时看到正负，推荐）

```
U 端子 ── 22Ω/5W ── V 端子
pwm 0.55 0.45 0.45  → 峰顶 U 高 / V 低 → I ≈ 545mA
期望：ia ≈ +545mA，ib ≈ −545mA，ic ≈ 0
```

> 功率电阻请用 **5W 以上**；电流必须留在 **±1.32A** 量程内。

### 6.2 实测记录：接电机（2026-10-25，`pwm 0.55 0.45 0.45`）

电机三根线全接（星形），线电阻 **4.6Ω**（两相串联）→ 每相 R = 2.3Ω。

| 项 | 实测 | 理论 | 结论 |
|---|---|---|---|
| raw | 1526 / 2310 / 2289 | —— | 相对零点 2047/2047/2045 都偏离 |
| 电流（改符号前） | **−335 / +169 / +157 mA** | 348 / 174 / 174 mA | 幅值误差 **−4%** |
| KCL | −335 + 169 + 157 = **−9 mA** | 0 | ✅ 三路一致 |
| A→(B∥C) 回路 | | R + R/2 = 3.45Ω，(0.55−0.45)×12V = 1.2V → **348mA** | ✅ |

**两个结论**

1. **增益正确**：幅值与用线电阻算出的 348mA 差 4%；
2. **极性相反**：A 相占空比最高（电流应流出 A 桥臂），raw 却低于零点 →
   `CUR_SIGN` 已改为 **`-1.0f`**（#30），改后 `ia` 为正。

> 注意：这是**纹波峰值**附近的瞬时值（采样点靠近峰顶），与万用表测的平均值不完全相同；
> 本例差距很小，说明该电机在 20kHz 下纹波不大。

## 7. 已知限制与 TBD

### 7.1 单 ADC 顺序采样的相位误差（重要）

三相互差最大 **2.61 µs**。以电频率 f_e 计算，误差角 = `2π·f_e·2.61µs`：

| 电频率 | 电角误差（rank1 vs rank3） | 影响 |
|---|---|---|
| 100 Hz | 0.094° | 可忽略 |
| 500 Hz | 0.47° | 可忽略 |
| 1000 Hz | 0.94° | 可忽略 |
| 2000 Hz | 1.88° | 增益误差 ~0.05%，可接受 |

**结论：20kHz PWM + 常见电机（电频率 < 1kHz）下，单 ADC 顺序采样完全够用，不必上双 ADC。**
（真实误差还包含采样保持的孔径时间，但量级相同。）

**唯一例外**：若三相电流严重不平衡或转速极高（>30000rpm+多极对），
再考虑 ADC1+ADC2 双 ADC 同步（ADC1 采 1 相、ADC2 采 2 相，耗时降到 1.74µs）。

### 7.2 其他

- 【已定】Rshunt=25mΩ、INA240 REF1=AGND/REF2=A3V3（VREF=1.65V）、VREF+=3.3V
- 【已知】INA240 输出已有 R18/R6/R8 10Ω + 22pF（截止≈723MHz，仅防振，无抗混叠作用）；若噪声大可改 1kΩ+1nF
- 【已知限制】ADC 常规组里多配了一个 CH17（`adc.c` 第 69~78 行），
  与注入组 rank1 重复，因软件触发且未使能所以不会执行。
  **建议**：CubeMX 里把常规组关掉（NbrOfConversion=0），或改作 Vbus 采样通道。
- 【已知限制】`Overrun = ADC_OVR_DATA_PRESERVED`，注入组在 JEOC 未及时清除时会覆盖数据，
  不会丢触发，符合 FOC 需求（宁可丢一拍数据也不能停）。
- 【已知限制】零漂会随温度漂移（INA240 的 offset drift 约 1µV/°C → 0.5 LSB/°C@5mΩ），
  长时间运行需考虑跑中点自动校准（暂不做，S8 再评估）。
