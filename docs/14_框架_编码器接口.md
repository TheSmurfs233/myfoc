# 子框架 · 编码器接口（MT6701）

---

## 1. 职责边界

- **管**：MT6701 的 SPI 读取、原始值 → 机械角 → 电角度、方向与零位标定、速度估算。
- **不管**：无感观测器（本项目为有感方案）；PWM 发波。

---

## 2. 接口

```c
/* User/Mid/mid_angle.h */
typedef struct {
    uint16_t raw;         /* 14bit 原始角度 0~16383 */
    float    mech_rad;    /* 机械角 0~2π */
    float    elec_rad;    /* 电角度 0~2π（= mech×pp + offset 后取模） */
    int8_t   dir;         /* +1 / -1，标定得到 */
    float    offset_rad;  /* 零位偏移（标定得到） */
    float    speed_rpm;   /* 转速，滤波后 */
    uint8_t  err;         /* 读取错误标志（CRC/超时/角跳变） */
} angle_t;

void  mid_angle_init(void);
void  mid_angle_update(void);                 /* 读一次传感器并更新（可在 ISR 或主循环） */
const angle_t *mid_angle_get(void);
void  mid_angle_calib_zero(void);             /* 把当前机械角设为电角度 0 */
void  mid_angle_calib_dir(void);              /* 记录方向 */

/* User/Bsp/bsp_spi_enc.h */
uint16_t bsp_mt6701_read_raw(uint8_t *err);
```

## 3. 关键参数

### 3.1 当前 SPI1 配置（需按 MT6701 手册复核）

| 项 | 当前值 | 说明 |
|---|---|---|
| 模式 | Master，2Lines，8bit，MSB first | spi.c |
| CPOL/CPHA | **CPOL=0, CPHA=1（Mode 1）** | ⚠ 需复核 |
| 波特率 | PCLK2/16 = **10.625 MHz** | ⚠ 偏高 |
| NSS | 软件，`CSN = PA15`（GPIO 推挽，初值高） | gpio.c |
| 引脚 | SCK=PB3, MISO=PB4, MOSI=PB5 | spi.c |

### 3.2 MT6701 特性（已核对数据手册 Rev1.8）

- 磁编，**14 bit 绝对角度**（16384 计数/圈，0.0219°/LSB）
- 输出方式：I2C / **SSI** / ABZ / UVW / 模拟 / PWM（由芯片引脚配置选）
- 本项目用 **SSI + 4 线（含 CSN）**
- 角度输出系统延时 **< 5 µs**
- SOP-8 引脚复用：pin6=DO、pin7=CLK、pin8=CSN

### 3.3 SSI 协议（已确认，与当前 SPI 配置匹配）

#### 3.3.1 帧格式：24 bit

| 位段 | 内容 | 说明 |
|---|---|---|
| `D[13:0]` | **14 bit 绝对角度** | D13 = MSB |
| `Mg[3:0]` | 4 bit 磁场状态 | 见下表 |
| `CRC[5:0]` | 6 bit 校验 | **多项式 X⁶+X+1**，覆盖前 18 位，MSB 先入 |

角度换算：`angle_deg = D[13:0] / 16384 × 360`

磁场状态 `Mg[3:0]`：

| 位 | 含义 |
|---|---|
| `Mg[1:0]` | 0=正常 1=磁场过强 2=磁场过弱 3=保留 |
| `Mg[2]` | 1=旋钮被按压（PUSH 功能） |
| `Mg[3]` | 1=**超速**（转速超出芯片能力，此时角度不可信） |

⚠ `Mg[3]`（超速位）在 FOC 里必须检查，超速时角度会跳变，直接拿去做 Park 变换会炸。

#### 3.3.2 时钟极性与边沿（关键）

> 手册原文：*"DO 信号在 CLK 的**上升沿**发生变化，建议在 CLK 的**下降沿**采集数据。"*

→ 主机在**下降沿采样** → **SPI Mode 1（CPOL=0, CPHA=1）**

**当前 CubeMX 配的就是 `CPOL_LOW + CLKPhase_2EDGE`（Mode 1），无需改动。** ✅

#### 3.3.3 时序参数

| 参数 | 最小值 | 说明 |
|---|---|---|
| `TCLK` | **64 ns** | → SCK 上限 **15.6 MHz** |
| `TCLKL` / `TCLKH` | 30 ns | 占空比 |
| `TH` | 100 ns | CSN 拉低后到第一个时钟沿的间隔 |
| `TL` | 0.5×TCLK | 最后一个时钟沿到 CSN 拉高的间隔 |
| `TDV` | ≤15 ns | 上升沿后数据有效时间 |

当前 SCK = **10.625 MHz**（PCLK2/16）→ `TCLK = 94ns > 64ns` ✅，
`TCLKL/TCLKH = 47ns > 30ns` ✅，`TDV 15ns < 47ns`（下降沿采样有余量）✅

**结论：10.625MHz 可以直接用，不用降速。**

⚠ 唯一要注意：CSN 拉低后要**等 ≥100ns 再发第一个时钟**（HAL 的 `HAL_SPI_TransmitReceive`
从 CSN 拉低到第一个 SCK 只有几个指令周期 ≈ 20~30ns，**不够**）。实现时在
`bsp_mt6701_read_raw()` 里 CSN 拉低后加 `for(volatile int i=0;i<20;i++);`（≈120ns）。

#### 3.3.4 为什么要加 CRC

24 bit 里有 6 bit CRC，`CRC-6 poly=0x03 (x⁶+x+1)`。
SPI 线上被电机开关噪声干扰时，CRC 能挡掉错误角度。

**建议**：S5 先关掉 CRC 校验（只取角度），确认通信稳定后再打开；
打开后若误码率居高不下，说明走线/屏蔽有问题，应优先改硬件而不是关掉校验。

### 3.4 时钟模式与速率的结论

- 当前 **Mode 1 @10.625MHz** 完全符合手册，**不需要任何修改**。
- 若调试时通信不上，先用逻辑分析仪确认：CSN 拉低后有没有 SCK、MISO 有没有数据。
  仍不通就把 SCK 降到 5.3MHz（`SPI_BAUDRATEPRESCALER_32`）排查。

### 3.5 角度处理

```c
/* 1) 原始 → 机械角 */
mech = raw * (2π / 16384.0f);

/* 2) 方向修正（标定得到） */
if (dir < 0) mech = 2π - mech;

/* 3) 零位偏移 */
mech = wrap_2pi(mech - offset_mech);     /* 使转子磁极与 A 相轴对齐时 mech=0 */

/* 4) 电角度 */
elec = wrap_2pi(mech * POLE_PAIRS);
```

**零位标定方法（S5）**：给 d 轴通固定电流、q 轴给 0（`ALIGN` 状态），
转子被拖到 A 相轴方向，此时读到的 mech 就是 `offset_mech`。

### 3.6 速度估算

在 ADC ISR（20kHz）里更新角度，速度用**差分 + 一阶低通**：

```c
delta = wrap_pi(elec - elec_prev);            /* 处理 2π 翻转 */
speed_raw = delta * (1 / TS) / (2π * POLE_PAIRS) * 60;   /* rpm */
speed_f += KF * (speed_raw - speed_f);        /* KF ≈ 0.05~0.2 */
```

【TBD】低速时差分噪声大，若需要低速性能，改用 M 法（测周期）或 PLL 跟踪观测器，S7 再定。

## 4. 时序/数据流

```
FOC ISR (20kHz，峰顶后 2.61us)
    │
    ├─ mid_angle_update()
    │     ├─ CSN 拉低
    │     ├─ 读 2~3 字节（阻塞式，1.6us@10MHz）
    │     ├─ CSN 拉高
    │     ├─ 解析 → mech → elec
    │     └─ 速度差分
    │
    └─ foc_core_step(elec, ia, ib, ic)
```

**耗时风险**：阻塞式 SPI 读在 ISR 内会占 1.6~3.2µs。当前预算内可接受，
但如果扩到 3 字节 24bit 帧或降速到 5MHz，耗时翻倍。

**两个可选优化（S5/S6 视实测决定）**
| 方案 | 做法 | 优缺点 |
|---|---|---|
| A. 上周期角度 | 本周期用上次读到的角度（延迟 50µs） | 零耗时，但引入 0.05ms 相位滞后，高速误差大 |
| B. SPI DMA | TIM1 CH4 触发 SPI DMA，FOC ISR 直接读结果 | 无 CPU 占用，最佳，但配置复杂 |
| C. 保持阻塞 | 中断内直读 | 最简单，1.6µs 可接受（推荐先做这个） |

## 6. 验证方法（S5 台架清单）

1. **通信**：读 raw 在 0~16383 之间变化，CSN 拉低时有 SCK 输出（示波器）。
2. **线性**：手动匀速转一圈，采集 raw 序列，应单调（或单调反向）递增，无跳变、无卡死。
3. **分辨率**：静止时 raw 抖动应 ≤ ±2 LSB（磁铁同心度和气隙正常的前提下）。
4. **方向**：按电机正转方向转，`dir` 应为 +1。
5. **电角度**：`ALIGN` 状态通 d 轴电流前后，elec 变化应 < 几度（零位对了）。
6. **电角度连续性**：开环拖动电机，elec 应连续变化无阶跃（若有阶跃 → 极对数错）。

## 7. 已知限制与 TBD

- 【已定】SSI 24bit 帧（14b 角度 + 4b 状态 + 6b CRC），SPI Mode 1 @10.625MHz
- 【已定】TCLK min 64ns → SCK 上限 15.6MHz，当前 10.625MHz 安全
- 【TBD】磁铁安装：同心度、气隙、是否偏心（决定角度噪声）
- 【TBD】是否需要 ABZ 作为冗余/备用
- 【已知限制】SPI 阻塞读占用 ISR 时间，见 4 节三个方案
- 【已知限制】14bit 分辨率（0.022°/LSB）在多极对电机上电角度量化误差 = 0.022°×PP，
  如 PP=7 → 0.15°。电流环够用；低速位置环可能有抖动。
