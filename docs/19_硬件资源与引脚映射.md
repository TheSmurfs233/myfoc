## 2. 功率级拓扑

```
DC_BUS(12V) ──┬──────────────┬──────────────┐
              │              │              │
            Q1.1(P)        Q2.1(P)        Q3.1(P)      ← HO1/2/3 驱动（P-MOS）
              │              │              │
        U ────┼──── V ───────┼──── W ───────┼──── 电机
              │              │              │
            Q1.2(N)        Q2.2(N)        Q3.2(N)      ← LO1/2/3 驱动（N-MOS）
              │              │              │
            R1 25mΩ        R2 25mΩ        R3 25mΩ       ← 低侧采样
              │              │              │
             PGND ──────────┴──────────────┘
```

- **MOSFET**：AO4606（SOP-8，N+P 互补双管，30V/6A，Rds(on)<30mΩ@10V，Ciss=255pF，Qg=5.2nC，Vgs(th)=1.2~2.4V）
- **驱动**：EG3033（三相 P/N MOS 驱动，SOP-16）
  - `HINx` 高有效 → 控制 `HOx` → **P-MOS**（"1"=开）
  - `LINx` 高有效 → 控制 `LOx` → **N-MOS**（"1"=开）
  - **真值表关键**：`HIN=LIN=1` 或 `HIN=LIN=0` → **两管全关**（内部互锁，永不直通）
  - 内置死区 **DT=60ns（typ）**
  - HO 驱动电压 = VCC2−11V ~ VCC2（即 P-MOS 的 Vgs = −11V，匹配 AO4606 的 −10V 规格书值）
  - LO 驱动电压 = 0 ~ 11V
  - HO 灌电流仅 **40mA**（P-MOS 关断慢的主因），LO 灌电流 0.28A
- **供电**：EG3033 支持 6~36V（VCC2），内置 5V LDO；板上有 LM317 产生 5V、RT9013-33 产生 3.3V

### 2.1 为什么 TIM1 的 CHx/CHxN 极性与 EG3033 天然匹配

| TIM1 状态 | CHx(HIN) | CHxN(LIN) | EG3033 输出 | 桥臂状态 |
|---|---|---|---|---|
| CNT < CCR（有效电平） | 1 | 0 | HO 开 / LO 关 | 上管通 |
| CNT ≥ CCR | 0 | 1 | HO 关 / LO 开 | 下管通 |
| **死区期间** | **0** | **0** | **双关** | **安全** |
| **MOE=0（封波）** | **0** | **0** | **双关** | **安全** |

结论：**不需要做任何极性取反**，TIM1 的死区与封波行为正好落在 EG3033 的安全区。

### 2.2 死区取值（已定：DTG=4 / 23.5ns 标称，实际 60ns）

计算依据见 `12_框架_SVPWM与发波.md` 第 3.3 节。一句话：
AO4606 的 P 管关断(~80ns) 快于 N 管开通到 Vgs(th)(~157ns)，
**自然死区已有 ~96ns 裕量**，EG3033 内部 60ns 再兜一层，所以 TIM1 侧只需给最小值。

## 3. 电流采样链路（重要）

```
U 相下管源极 ── R1 25mΩ ── PGND
                    │  IN+ (IU+)      INA240A2 (U6)
                    │  IN- (IU-)      ├─ OUT ─ R18 10Ω ─ ISU ─→ PA4 (ADC2_IN17)
                    │                 ├─ VS  ─ A3V3
                    └─────────────────┼─ REF1 ─ AGND
                                      └─ REF2 ─ A3V3
```

| 项 | 值 | 说明 |
|---|---|---|
| 采样电阻 | **25 mΩ**（实际焊接） | ⚠ 原理图标注 10mΩ，实物为 25mΩ |
| 放大器 | INA240A2 × 3 | 增益 **50 V/V**，带宽 400kHz |
| REF1 / REF2 | **AGND / A3V3** | → `VREF = (0+3.3)/2 = 1.65V`，标准**双向**偏置 |
| 零电流输出 | 1.65 V → 码值 ≈ **2048** | |
| 灵敏度 | 25mΩ × 50 = **1.25 V/A** | |
| 分辨率 | **0.645 mA/LSB** | 0.806mV ÷ 1.25V/A |
| 双向量程 | **±1.32 A** | 受 1.65V / 1.25V·A⁻¹ 限制 |
| 输出 RC | 10Ω + 22pF | 截止 ≈ 723MHz，几乎只是防振 |

⚠ **±1.32A 的量程很小**。如果电机额定电流超过 1A，S3 阶段会撞到饱和，届时只能换小阻值采样电阻。

## 4. 母线电压采样

```
DC_BUS ── R20 12kΩ ──┬── VBUS_A ── PA1（待配 ADC）
                     │
                  R21 2kΩ
                     │
                    GND
```

| 项 | 值 |
|---|---|
| 分压比 | (12k+2k)/2k = **7.0** |
| 每 LSB | 0.806mV × 7 = **5.64 mV** |
| 12V 时 | 1.714V → 码值 2128 |
| 最大可测 | **23.1 V**（3.3V × 7） |
| 过压阈值 | 13.8V（1.15×12）→ 码值 2447 |
| 欠压阈值 | 9.0V → 码值 1596 |

## 6. 通信接口

| 接口 | 引脚 | 对端 | 用途 |
|---|---|---|---|
| USART1 | PB6/PB7 | **CN3 排针**（WAFER-SH1.0-6P） | **本工程调试口**，VOFA+ 走这里 |
| USART2 | PA2/PA3 | 板载 **CH340N** → USB Type-C | 一根线搞定供电+通信（本工程暂不用） |
| SPI1 | PB3/PB4/PB5 + PA15 | MT6701 | 角度读取 |
| FDCAN1 | PA11/PA12 | SN65HVD230 → CN2 | 未启用 |
| SWD | PA13/PA14 | H1 排针 | 下载调试 |

⚠ **注意**：`USART1` 接的是 1.0mm 间距 6P 排针，需要自备 1.0mm 转 2.54mm 线或转接板；
如果想直接用板载 USB 口，就必须改用 USART2（需在 CubeMX 增加配置）。
