### ⚠️ 烧录时别下错工程

两个工程都叫 `myfoc`，**必须选这一份**：

```
D:\Embedded\STM32\wb_foc\MDK-ARM\myfoc\myfoc.hex     <- 正确（约 68 KB）
D:\Embedded\STM32\workspace\myfoc\MDK-ARM\...        <- 旧工程（约 344 KB）
```

下错的话所有命令都回 `ERR command`（那是 workspace 工程里的字符串）。
**判据**：`ver` 应打印 `board = Board_v2/STM32G431KBT6` 和 `build = ... #13`。

### 固件版本识别

`board_cfg.h` 里的 `FW_BUILD_ID`（当前 **13**）是唯一权威版本标识，`ver` 会打印。
**不要拿 `__DATE__/__TIME__` 判断新旧** —— Keil 增量编译时它不会随每次 build 刷新
（见 00 号日志 S1-acc）。每次改固件记得把 `FW_BUILD_ID` +1。
