# 21 · 框架：SVPWM 与 V/f 开环（S4）

> 对应阶段：S4。实现文件：`User/Alg/alg_svpwm.c`、`User/Alg/alg_vf.c`、
> `User/App/app_main.c`（task_vf）、`User/Cfg/board_cfg.h`（VF_* 宏）。

---

## 1. 目标与边界

| 项 | 内容 |
|---|---|
| 目标 | 电机开环转起来：相电流正弦、三相 120° 对称、`ia+ib+ic≈0` |
| 手段 | V/f 恒压频比 + 低速 IR 补偿 + 电流软限流 |
| 不做 | 位置/速度反馈（S5 才有编码器）、电流闭环（S6）、保护（S7） |
| 频率范围 | 0~**200 Hz 电频率**（≈1714 rpm，7 对极） |

---

## 2. 数据流

```
20kHz ADC 帧（TIM1_CC4 触发）
   └─ bsp_adc JEOC ISR：锁存 JDR1~3、frames++
        └─ 主循环 task_adc()：mid_current_update()
             └─ task_vf()                        ← S4 新增，每帧一次
                  ├─ alg_vf_step(ts=50us)        角度累加 + 频率斜坡 + dir
                  ├─ alg_vf_mod_index()          V/f 曲线 + 限幅 + foldback
                  ├─ alg_svpwm(theta, m)         → 三相占空比
                  └─ bsp_pwm_set_duty()          CCR 预装载，下个 UEV 生效
```

**为什么每帧一次**：帧间隔是精确的 50µs，角度积分无抖动；20kHz 下 200Hz 每周期仍有
100 个点。S6 的电流环会搬进同一个位置（ISR 内）。

---

## 3. SVPWM（min-max 注入）

```
d_a = 0.5 + 0.5·m·cos(θ)
d_b = 0.5 + 0.5·m·cos(θ − 120°)
d_c = 0.5 + 0.5·m·cos(θ + 120°)
off = (max + min)/2 − 0.5          ← 零序注入
d_i = d_i − off
```

性质：

| 性质 | 说明 |
|---|---|
| 线电压不变 | 注入的是共模量，`d_a − d_b` 不受影响 |
| `max + min == 1` | 三相始终对称于 0.5，不削顶 |
| 线性区到 **m = 1.1547** | 六步等效；纯正弦调制只能到 1.0 |
| 线电压幅值 | `V_LL_peak = 0.866 · m · Vdc` |

`m = 0` 时三相都是 0.5（零矢量）。

**dir（相序）**：`θ → −θ` 精确等价于交换 B/C 两相，
即反转旋转磁场。注意：**Vα、Vβ 同时取反只是转 180°，不是反转**。

---

## 4. V/f 曲线

```
V_LL_rms(f) = VF_BOOST_V + VF_K_V_PER_HZ · f
m(f)        = 1.633 · V_LL_rms / Vdc        （再限幅到 VF_M_MAX）
```

推导：`V_LL_rms = (√3/2)/√2 · m · Vdc = 0.6124·m·Vdc` → `m = 1.633·V/Vdc`。

| 宏 | 默认 | 含义 |
|---|---|---|
| `VF_BOOST_V` | 1.5 V | 低速压降补偿（≈0.33A × 4.6Ω） |
| `VF_K_V_PER_HZ` | 0.026 V/Hz | 12V / 462Hz（KV=330、7 对极） |
| `VF_M_MAX` | 0.95 | 留 5% 裕量 |
| `VF_F_MAX` | 200 Hz | 第一版上限 |
| `VF_ACC_HZ_PER_S` | 20 Hz/s | 0→200Hz 约 10s |

预算（空载）：

| f | V_LL | m | 期望电流 |
|---|---|---|---|
| 10Hz | 1.76V | 0.24 | ≈0.33A |
| 50Hz | 2.80V | 0.38 | ≈0.33A |
| 100Hz | 4.10V | 0.56 | ≈0.33A |
| 200Hz | 6.70V | 0.91 | ≈0.33A |

## 5. 限流与跳闸

量程只有 **±1.32A**，而 12V 堵转要 3.5A，所以开环必须自带护栏：

| 级别 | 条件 | 动作 |
|---|---|---|
| 软限流 | `max|I| > 1.00A` 连续 20 帧 | `m_scale ×= 0.98`（最低 0.30） |
| 恢复 | `max|I| < 0.80A` | `m_scale ×= 1.001`（上限 1.0） |
| **硬跳闸** | `max|I| ≥ 1.25A` 连续 5 帧 | `MOE=0`、状态 → `FAULT`、只允许 `stop` 复位 |

> 这是 S7 正式保护之前的临时护栏，但**必须有**：一旦失步或堵转，ADC 会削顶。

## 6. 命令

| 命令 | 说明 |
|---|---|
| `vf <hz>` | 设目标电频率并开始调制（需先 `start`） |
| `vf off` | 停止调制，占空比回 50% |
| `acc <hz/s>` | 斜坡率 1~200 |
| `dir <0\|1>` | 1 = 反转相序（软件 θ 取反） |

`vf` 激活时 `pwm` 被拒（`ERR vf active`），避免两套占空比打架。

`stat` 增一行：

```
vf       = ON 100.0/200.0 Hz, m=0.56, I=0.34 A, dir=0
```

## 7. 主机测试（不接硬件）

| 用例 | 判据 |
|---|---|
| m=0 → 三相 0.5 | 零矢量 |
| 720 点扫描 | 占空比 ∈ [0,1]，`max+min == 1` |
| 线电压幅值 | `0.866·m`，误差 <0.5% |
| θ=0 | A 相最高、B==C |
| θ→−θ | 精确交换 B/C |
| 斜坡 | 20Hz/s，1s 后 20Hz，最终停在目标 |
| 角度 | 步进 `2πf·ts`，长时间运行仍回绕在 [0,2π) |
| V/f | 10/200/500Hz 三点与公式一致（含限幅） |
| foldback | `m_scale=0.5` 时 m 减半 |

## 8. 台架步骤

1. `vf 5` → 观察三相电流正弦、`|I|<0.5A`；
2. 若抖动/不转 → `dir 1`；
3. `vf 20 → 50 → 100 → 200`，每档 3s，看 `sat=0`、KCL≈0；
4. 斜坡：`vf 150`，观察加速不掉步；
5. 限流：轻捏轴，确认 foldback 生效、电流不冲到 1.32A；
6. 跳闸：短接一相，确认 `FAULT` 并封波。

### 8.1 实测结果（2026-10-25，#31，7 对极 / 12V / 330KV）

| 目标 | 到达 | m 实测 | m 理论 | I 峰值 | sat | KCL |
|---|---|---|---|---|---|---|
| 5 Hz | 5.00 | 0.22 | 0.222 | 0.54 A | 0 | ≤23 mA |
| 20 Hz | 20.00 | 0.27 | 0.275 | 0.59 A | 0 | 7 mA |
| 50 Hz | 50.00 | 0.38 | 0.381 | 0.68 A | 0 | 5 mA |
| 100 Hz | 100.00 | 0.56 | 0.558 | 0.81 A | 0 | 11 mA |
| 200 Hz | 200.00 | 0.91 | 0.912 | 0.67 A | 0 | 8 mA |

- **`dir = 0` 时面向电机逆时针**（S5 标定编码器方向时用这个基准）；
- 5Hz → 0.714 rps → **42.9 rpm**，与 7 对极吻合；
- 电流在 100Hz 达峰 0.81A（铁损），低于 1.0A foldback；
- 200Hz 时电流降到 0.67A：电机已升温（R 变大）+ ωL 抬升阻抗。

## 8.2 相位探针 `phase`（控制链每段花了多久）

`prof` 用 **DWT** 量"每个被插桩函数多久"，`phase` 则把 20kHz 控制链拆成**同帧内的三段**：

| 标记 | 区间 | 含义 |
|---|---|---|
| `isr cnt` | —— | 中断入口时的 TIM1 CNT（采样点在周期里的位置，peak = 4250） |
| `pick` | 中断入口 → 主循环取走该帧 | 调度延迟（受主循环周期影响） |
| `comp` | 取走 → 占空比算完 | V/f + SVPWM 的计算耗时 |
| `wr` | 算完 → CCR1~3 写完 | 写寄存器耗时 |

三段都取自**同一帧**（`t_pick`/`t_comp` 逐级传递），所以可以直接相加得到
"从中断到控制量落地"的总时间。`phase reset` 清零。
用它判断"S6 的电流环能不能在谷底 UEV 之前算完"。

> **探针会跟随 `prof` 开关**：`prof off` 时 `phase` 标记与 ISR 里的 DWT/CNT 打点全部停止，
> 控制链回到"零探针"状态（主循环从 130kHz 提到 170kHz）。S6 评估实时性请用这个状态。
> `phase` 的字段单位是 0.1µs（`PHASE_CYC_PER_US = 170`）。
