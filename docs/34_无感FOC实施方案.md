# 34 · 无感 FOC 实施方案

> 分支：`feature/sensorless-foc`（**不合并回 `master`**，见第 0 节决策 4）

## 0. 已确认的决策

| # | 决策 | 说明 |
|---|---|---|
| 1 | **保留编码器** | 命令切换"有/无感"；编码器同时充当观测器的真值参考 |
| 2 | **最低无感转速 300 rpm** | 低于此转速用 I/f 开环拖动覆盖 |
| 3 | **不改硬件** | 不加相电压采样、不加硬件过流；纯软件实现 |
| 4 | **不合并回 `master`** | `master` 保持有感稳定线，本分支长期独立 |
| 5 | 先在**影子模式**验证误差 | 观测器达标前不接入控制 |
| 6 | **目标是可移植** | 换电机 + 无编码器时只改参数、不重写算法（见第 5 节） |

## 1. 总体思路：三段式推进

```
阶段 1「影子模式」  编码器照常驱动控制，观测器只在后台运行 → 只测量、零风险
阶段 2「I/f 启动」  开环拖动转子，同时等观测器收敛
阶段 3「闭环无感」  切换后由观测器提供角度，编码器可断开
```

**核心原则**：任何一步失败都能退回上一步，且不破坏现有有感功能。

## 2. 算法设计

### 2.1 数据流

```
         ┌─────────────────────────────────────────┐
         │  电流环输出 vα, vβ                       │
         │  （已有，无需从占空比重建，见 2.2）        │
         └──────────────────┬──────────────────────┘
                            │
 ia,ib,ic ──Clarke──► iα,iβ │
                │           ▼
                │   ┌───────────────────────────────┐
                │   │ eα = vα − R·iα − L·diα/dt     │  反电动势
                │   │ eβ = vβ − R·iβ − L·diβ/dt     │
                │   └───────────────┬───────────────┘
                │                   │ 一阶低通 (OBS_LPF_HZ)
                │                   ▼
                │   ┌───────────────────────────────┐
                │   │ ed =  eα·cosθ̂ + eβ·sinθ̂       │  角度误差
                │   │ eq = −eα·sinθ̂ + eβ·cosθ̂       │  ≈ ωe·ψf
                │   └───────────────┬───────────────┘
                │                   ▼
                │   ┌───────────────────────────────┐
                └──►│ PLL（复用 alg_pll）            │
                    │  ω̂ += ki·ed·dt                │
                    │  θ̂ += (ω̂ + kp·ed)·dt         │
                    └───────────────┬───────────────┘
                                    │
                       θ̂ ──► Park（替代编码器角度）
                       ω̂ ──► 速度环反馈
```

### 2.2 为什么不需要"电压重建"

SVPWM 注入的零序分量 `v0` 在三相等量叠加：

```
va = vα + v0,  vb = vβ' + v0,  vc = vc' + v0

Clarke:  (2/3)(va − vb/2 − vc/2) = 原式 + (2/3)(v0 − v0/2 − v0/2) = 原式 + 0
```

**零序在 αβ 上完全抵消**，所以"占空比重建 → Clarke"与直接用 `vα/vβ` 等价。
直接用控制器输出更简单、无量化误差。

> 唯一差异：占空比重建能反映"最小脉宽截断/过调制"，而 `vα/vβ` 是理想指令。
> 在 `m ≤ 0.95` 的正常工作区内两者一致，因此不做重建。

**死区补偿**同理降级为可选（见第 9 节），先量出误差再决定。

### 2.3 为什么用 PLL 而不是 `atan2`

| 方法 | 问题 |
|---|---|
| `atan2(−eα, eβ)` | 每拍独立求解，`e` 的噪声直接变成角度抖动 → 转矩脉动；低速时信噪比更差 |
| **PLL** | 带惯性的跟踪，自带低通；输出连续的角度与转速；对瞬时异常鲁棒 |

### 2.4 关键公式与符号约定

```
eα = −ωe·ψf·sin(θe)
eβ = +ωe·ψf·cos(θe)

ed =  eα·cosθ̂ + eβ·sinθ̂ = ωe·ψf·sin(θ̂ − θe)     ← 误差项，PLL 驱动它归零
eq = −eα·sinθ̂ + eβ·cosθ̂ = ωe·ψf·cos(θ̂ − θe)
```

- `θ̂ = θe` 时：`ed = 0`、`eq = ωe·ψf`
- `eq` 也是**参数自检**的依据（应与 `ω̂·ψf` 一致，见 5.3）

### 2.5 复用现有代码

| 现有模块 | 复用方式 |
|---|---|
| `alg_pll.c` | 新增 `alg_pll_step_err(p, err, dt)`：直接吃 `ed`，跳过角度环绕 |
| `alg_clarke()` | 由 `ia/ib` 得 `iα/iβ`（`alg_foc.c` 已有） |
| `alg_foc` 的 `vα/vβ` | 观测器的电压输入（需在 `alg_foc` 里暴露） |
| `wave`/`rip`/`sstep` | 验收工具 |
| `vf` | I/f 启动可复用其频率斜坡思路 |

### S10.7 参数辨识与移植清单 ✅ **完成（#174，本机对账 #175）**

`sident` 把三个必须重标的常数变成一条命令，全程不需要编码器、不需要示波器：

| 量 | 怎么测 | 关键点 |
|---|---|---|
| R | d 轴两点法：`id` 稳在 0.30 A 与 0.60 A，各取 100 ms 平均 `vd`，`R = dv/di` | 转子被预对齐锁在 theta = 0，电流全在 d 轴，**不产生转矩**；两点法把逆变器压降和 ADC 偏置一起减掉（单点会读到 2.45~2.60 ohm，真值 2.30） |
| L | d 轴电流阶跃，逐帧最小二乘拟合 `vd - R*id = L*di/dt` | **本机测不出来**（见下），保留命令但默认不跑 |
| KE | I/f 拖到 `ID_KE_HZ` = 60 Hz 电频率，稳定 800 ms 后取反电动势幅值 / 观测转速 | 拖动电流 0.6 A、`sident` 自动开观测器；用矢量幅值而不是投影 `eq` |

前三段都在**强制 theta = 0 的帧**上跑，电机静止；只有 KE 段会转起来。

| 命令 | 做什么 | 耗时 |
|---|---|---|
| `sident` / `sident all` | R -> KE（**默认不测 L**） | 约 3 s |
| `sident r` | 只测 R | 约 1.2 s |
| `sident l` | 测 R + L（L 需要 R，输出带 `experimental`） | 约 2 s |
| `sident ke` | 直接从 I/f 拖动开始，跳过静止段 | 约 2 s |
| `sident stop` | 中止（KE 段会顺手停掉 I/f） | — |

输出（每次子测试一行，最后一行汇总并给出可直接粘贴的整数）：

```
 sident r 2.19 ohm (0.30A 0.66V, 0.60A 1.32V)
 sident ke 3.61 mV/(rad/s) (|e| 1.08 V at 54.0 Hz)
OK sident r 2.19 ohm, ke 3.61 mV/(rad/s)
 motor_cfg.h; r_ohm 2191 mOhm, ke_v_rad_s 3609 uV
```

换电机时按这个顺序做：

| # | 步骤 | 判据 |
|---|---|---|
| 1 | 改 `motor_cfg.h`：`pp`、`i_rated_a`、`i_max_a`、`rpm_max` | 编译通过（`MOTOR_CFG_ASSERT` 挡明显错误） |
| 2 | `mode 2` -> `start` -> `sident` | 打印三个值，且 R/L 与手册同量级 |
| 3 | 用打印的整数回填 `motor_cfg.h`，重新编译烧录 | 编译通过 |
| 4 | `align ol` 连做 10 次 | 10/10 拉到同一位置 |
| 5 | `sfoc go 300` | 起转 + 交接，`spd` 的 `meas` 跟得上 |
| 6 | `sfoc go` 扫 300 / 600 / 900 / 1200 rpm | 稳态误差 < 1%，`iq` 不饱和 |
| 7 | `sfoc go -300` ... `-900` | 反向同样稳定（#171 起符号自动处理） |
| 8 | 再跑一次 `sident ke` 复查 | 两次 KE 相差 < 10% |
| 9 | `prot` 查阈值后逐一触发 6 类保护 | 各自跳闸，`stop` 后可恢复 |

本机实测（2026-11-05，固件 #175，空载，母线 11.9 V）：

| 量 | 实测 | `motor_cfg.h` 声明 | 差 | 结论 |
|---|---|---|---|---|
| R | 2.173 / 2.184 / 2.202 ohm（3 次） | 2.30 | -4 ~ -5% | **可信**，极差 1.3% |
| KE | 3.70 ~ 3.89 mV/(rad/s)（5 次，均值 3.79） | 4.13 | -7 ~ -10% | **可信**，极差 5% |
| L | 0.29 mH（40 帧、5 帧两次都是这个数） | 0.50 | -42% | **不可信，别用** |

为什么 L 测不出来：这台电机 L/R = 0.5 mH / 2.3 ohm = **217 us**，在 20 kHz 下只有 4 个采样点。
闭环阶跃时 `vd` 和逐帧 `di/dt` 的配对被一帧的采样/PWM 延迟主导，结果稳定偏小 42%；
#175 加了“跳过饱和帧 / 跳过电流已稳帧”的护栏后样本数掉到 5、值却没变，说明不是样本问题而是方法极限。

有意思的是 5 次 KE 里 `|e|` 从 0.56 V 到 1.14 V 差了一倍（每次取样时转子滑差不同），
但 `|e|/omega_e` 始终落在 3.70~3.89 —— 因为 KE 是个**比值**，滑差同时改变分子和分母，这反而说明该方法不挑工作点。

因此：

- `sident` / `sident all` 默认只做 R + KE；`sident l` 仍可用，输出带 `experimental` 字样
- 汇总行**只列测到的东西**：默认跑只有 `r_ohm` 和 `ke_v_rad_s`，不会出现 `l_h 0 uH` 误导你往
  `motor_cfg.h` 里粘 0（`MOTOR_CFG_ASSERT` 也会拦，但被拦在编译期不如一开始就不给）
- **`motor_cfg.h` 继续用手册值（2300 mOhm / 500 uH / 4130 uV）**：观测器对 L 不敏感
  （800 rpm 下 0.2 mH 误差只贡献约 0.03 V 前馈），而 `OBS_TRIM_DEG` 的 -3.6 度是在 L = 0.5 mH 下标定的，
  换成 0.29 mH 要重标 trim，风险大于收益。实测值只作“换电机时量级对不对”的参照。

连跑注意：KE 段结束会把动能灌回母线（实测连跑三次后 `ERR fault overvoltage 15693 mV`），
改前只有 `stop` 能清。#175 起 `app_id_start()` 会先看母线，超过 `ID_VBUS_MAX_V` = 13.0 V 直接
返回 10 并报 `ERR bus ... V, wait for it to settle`。

## 5. 移植到其他电机（无编码器）

### 5.1 哪些能移植、哪些必须重标

| 项 | 可移植性 |
|---|---|
| 算法结构（反电动势 → ed → PLL、I/f、切换、失步检测） | ✅ 通用 |
| 代码（`alg_obs`/`alg_if`/`alg_pll`） | ✅ 通用 |
| 参数（R/L/KE/pp/J/限流/切换点） | ❌ 每台电机重新标定 |

### 5.2 参数辨识（都不需要编码器）

| 参数 | 方法 | 依赖 |
|---|---|---|
| 极对数 | 查规格；或手转一圈数电周期 | 手动 |
| **R** | `align ol` 预定位 → 固定 `iq` 并**堵住转子** → `R = vq/iq` | `align ol` + `iq` + `foc` |
| **L** | 对齐后给 d 轴电压阶跃，`wave` 看 `di/dt` → `L = v·dt/di` | `wave` |
| **K_EMF** | V/f 空载跑到已知电频率，示波器量相电压峰值 → `K = V_peak/ω_e` | `vf` + 示波器 |
| J | 阶跃 `iq`，看加速度 → `J = Kt·i/α` | `iq` + `wave` |

> **#174 起这条手工路已自动化**：`sident` 一条命令完成 R/L/KE（见 §S10.7），
> 下面的表保留作为原理说明与手算复核用。

> **关键改造**：当前 `align` 依赖编码器判断转子是否停下。
> 无编码器时必须用**开环预定位**（固定矢量 → 等待 → 认为已对齐），即 S10.0 的 `align ol`。

### 5.2.1 辨识不需要额外仪器

| 参数 | 不依赖示波器的做法 |
|---|---|
| R | `align ol` 预定位（iq 取 **0.3 A**，低于堵转判据 0.6 A）→ 读 `foc` 的 vq → `R = vq/iq` |
| L | 用现有 `step` 命令的**上升时间**反推：`fc ≈ kp/(2πL)` → `L ≈ kp/(2π·fc)` |
| K_EMF | **S10.1 之后**用观测器算：V/f 空载运行，`\|e\|/ωe` 即 ψf（等价 KE） |
| J | 阶跃 `iq` 看加速度（`wave` 的 ch9） |

> 因此 KE 的辨识放在 **S10.3**（观测器可用之后），S10.0 的 `sident` 只负责 R 与 L。

### 5.3 无编码器时如何验证观测器

没有真值，但有 4 个自洽判据：

**① `id/iq` 比值（最实用，在线可用）**

角度误差 Δθ 会让 Park 失配，产生 d 轴电流：

```
id ≈ iq · sin(Δθ)
```

| `id/iq` | 推算角度误差 |
|---|---|
| 0.1% | 0.06° |
| 1% | 0.6° |
| 5% | 2.9° |
| 10% | 5.7° |

这是 `obs health` 打印的核心指标，**不依赖任何外部基准**。

> **前提**：必须在**稳态**（转速稳定、电流环闭环、无大加速）下读取，
> 且 `iq` 有一定幅值（建议 > 0.1 A），否则比值无意义。

**② `eq` 与 `ω̂·ψf` 的一致性**

观测器算出的 `eq` 应等于 `ω̂ × ψf`。偏差大 → R/L/KE 参数错，或观测器没收敛。

**③ 稳态转速重复性**

同一目标多次 `sstep`，稳态转速应一致。有系统性偏移说明参数错误。

**④ 同负载下的电流合理性**

相同机械负载，无感与有感的 `iq` 应接近。明显偏大 → 角度失配导致转矩打折。

### 5.4 硬件兼容性检查（换电机前必看）

| 项 | 本板限制 | 新电机要求 | 不满足怎么办 |
|---|---|---|---|
| 电流量程 | **±1.32 A** | 额定电流 ≤ 1 A | 改分流电阻或运放增益 |
| 母线电压 | 12 V | KE 允许目标转速 | 提高母线电压 |
| PWM 频率 | 20 kHz | 电感不宜 <0.3 mH | 提高 PWM 频率（改 ARR） |
| 电频率 | 20 kHz/40 = 500 Hz 上限 | `rpm/60×pp < 500 Hz` | 限制最高转速 |
| 采样拓扑 | 三相 inline | 任何三相电机 | 通用 |

### S10.6b 无编码器时的启动路径（#164）

`start` 一执行就会做编码器存活检测（`PROT_ENC_FRAMES` / `PROT_ENC_ZERO_FRAMES`）。
没装编码器时全零帧能骗过 CRC，10 ms 内就跳 `FAULT_ENCODER`，
用户还没来得及 `sfoc go`，无感模式进不去。

现在用 `mid_enc_seen_ok()` 区分：

| 情况 | 动作 |
|---|---|
| 开机后**从未**收到非零且 CRC 正确的帧 | 自动 `mid_enc_set_enabled(0)`，打警告，不跳闸 |
| 之前正常、运行中变全零/无更新 | 仍然 `FAULT_ENCODER` |

于是标准流程简化为：`mode 2` → `start` → `sfoc go <rpm>`，
有没有编码器都不用先手动 `enc off`。

### S10.8 起转与交接的转矩连续性（#166）

**问题**：电机散放在桌面上时，`sfoc go` 会甩动两次。两次都是转矩阶跃：

| 位置 | 阶跃 | 原因 |
|---|---|---|
| 预对齐 | 电流 0→0.6 A 用 100 ms | 转子被拉到 d 轴后欠阻尼振荡 |
| 预对齐 → 拖动 | 一帧内 d 轴 0.6 A 跳到 q 轴 | 0 → 17.3 mN·m（≈1800 rpm/s） |
| 交接 | `spd_ref` 从 0 起爬 | 误差 −310 rpm → −1.86 A，钳到 −1.2 A |

**措施**：

| 项 | 做法 | 参数 |
|---|---|---|
| 软斜坡 | `i_now` 按 `ramp_s` 上升 | `IF_I_RAMP_MS 300` |
| 交叉淡入 | `alg_if` 的 `xq` 0→1，`id = i_now*(1-x)`、`iq = i_now*x` | `IF_XFADE_MS 80` |
| 恒转矩 blend | 按 `cos(dth)/cos(dth*(1-w))` 缩放，抵消坐标系旋转带来的转矩放大 | 无新参数 |
| 交接无扰 | `spd_ref = rpm_now` + `alg_spd_preload(iq0)`（PI 积分 / 反馈滤波 / `ref_prev`） | 无新参数 |
| 预对齐加长 | 给振荡留时间 | `IF_ALIGN_MS 600` |

**真机结论（#166，2026-11-02）**：交接甩动消失；起转仅剩预对齐那一次轻微
摆动（定位过程，固有），用户判定可接受。

**为什么预置 `ref_prev`**：加速度前馈 `alpha = (ref − ref_prev)/ts`，
不预置时第一次运行就是 `(310 − 0)/0.001 × 0.1047 ≈ 32000 rad/s²`，
乘 `ff_acc = 3.11e-3` 得到约 100 A 的假电流指令（会被钳位，但方向是错的）。


### S10.10 释放时不再短路（#168）

**问题**：`sfoc off`（或任何没有角度源的释放）之后，`task_foc` 命令三相同占空比，
那不是"断电"，而是**三相短路**。转子还在转时反电动势直接灌进绕组：
1500 rpm 实测占空比 4 ms 内变 0.50/0.50/0.50、峰值 **1.316 A**（跳闸 1.28 A）、
约 0.5 s 衰减到 0，转子被硬刹停。

**措施**：

| 项 | 做法 |
|---|---|
| 判据 | `\|e\|² > COAST_E_MIN2`（0.20 V）→ 认为转子还在转 |
| 滑行 | 电流环继续跑，`id_ref = iq_ref = 0`，角度用观测器 → 用电压抵消反电动势，转矩≈0 |
| 退出 | `\|e\|` 掉到 0.20 V 以下（转子停了）或超过 `COAST_TICKS_MAX`（5 s） |
| 清零 | `app_start` / `app_stop` / `app_fault_raise` 都清滑行状态 |

**为什么不用观测器转速**：停机后观测器的 ω̂ 会自由漂（实测 1002 rpm 而 `|e|` 为 0），
把它当"还在转"的判据会永远滑行。
### S10.11 释放后的两处残留（#169）

| 残留 | 现象 | 改法 |
|---|---|---|
| `sfoc off` 没停速度环 | 无编码器时 `s_spd.on` 仍为 1、目标残留 1500 rpm；速度环每 1 ms 往 `s_foc_info.iq_ref` 写饱和值 1.200，滑行分支每 50 µs 又写回 0，于是波形偶发单帧 +1.20 A | `sfoc off` 里 `mid_enc_enabled() == 0u` 时补 `app_spd_off()` |
| 滑行期 ch8/ch9 变 0 | #168 的滑行分支既不是 `s_sfoc` 也不是 `s_if.run`，波形掉到 0，转速不可见 | ch8/ch9 增加 `else if (s_coast != 0u)` 分支，取观测器角度/频率 |

> 实测：10 s 保持实验（`sfoc168hold.log`，4186 帧、9 条文本行）确认该残留**不会**
> 误跳堵转 —— 堵转判据读 `s_foc_info.iq_ref`，而该值 49/50 µs 都是 0，500 ms 去抖
> 每次被清零。所以这属于显示与状态整洁问题，不是安全问题。

### S10.13 反向闭环（#171）

| 问题 | 处理 |
|---|---|
| PLL 撞限后自由旋转 | `OBS_RAIL_RATIO` + `HO_RAIL_MS` 判据，释放并报 `ERR obs speed railed` |
| 反向转矩符号与正向相反 | 无感态 `omega_e < 0` 时速度环输出取反 |
| 交接角差无符号 | 新增 `s_ho_ds`，`sfoc` 查询印有符号的 `ds` |
