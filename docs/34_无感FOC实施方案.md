# 34 · 无感 FOC 实施方案

> 分支：`feature/sensorless-foc`（**不合并回 `master`**，见第 0 节决策 4）
> 前置评估：`33_无感FOC评估.md`（硬件能力、速度边界、原理）
> 本文是**实施计划**，那篇是**可行性分析**；若两者冲突，以本文为准。

## 0. 已确认的决策

| # | 决策 | 说明 |
|---|---|---|
| 1 | **保留编码器** | 命令切换"有/无感"；编码器同时充当观测器的真值参考 |
| 2 | **最低无感转速 300 rpm** | 低于此转速用 I/f 开环拖动覆盖 |
| 3 | **不改硬件** | 不加相电压采样、不加硬件过流；纯软件实现 |
| 4 | **不合并回 `master`** | `master` 保持有感稳定线，本分支长期独立 |
| 5 | 先在**影子模式**验证误差 | 观测器达标前不接入控制 |

---

## 1. 总体思路：三段式推进

```
阶段 1「影子模式」  编码器照常驱动控制，观测器只在后台运行 → 只测量、零风险
阶段 2「I/f 启动」  开环拖动转子，同时等观测器收敛
阶段 3「闭环无感」  切换后由观测器提供角度，编码器可断开
```

**核心原则**：任何一步失败都能退回上一步，且不破坏现有有感功能。

## 2. 算法设计

### 2.1 数据流

```
         ┌─────────────────────────────────────────┐
         │  电流环输出 vα, vβ                       │
         │  （已有，无需从占空比重建，见 2.2）        │
         └──────────────────┬──────────────────────┘
                            │
 ia,ib,ic ──Clarke──► iα,iβ │
                │           ▼
                │   ┌───────────────────────────────┐
                │   │ eα = vα − R·iα − L·diα/dt     │  反电动势
                │   │ eβ = vβ − R·iβ − L·diβ/dt     │
                │   └───────────────┬───────────────┘
                │                   │ 一阶低通 (OBS_LPF_HZ)
                │                   ▼
                │   ┌───────────────────────────────┐
                │   │ ed =  eα·cosθ̂ + eβ·sinθ̂       │  角度误差
                │   │ eq = −eα·sinθ̂ + eβ·cosθ̂       │  ≈ ωe·ψf
                │   └───────────────┬───────────────┘
                │                   ▼
                │   ┌───────────────────────────────┐
                └──►│ PLL（复用 alg_pll）            │
                    │  ω̂ += ki·ed·dt                │
                    │  θ̂ += (ω̂ + kp·ed)·dt         │
                    └───────────────┬───────────────┘
                                    │
                       θ̂ ──► Park（替代编码器角度）
                       ω̂ ──► 速度环反馈
```

### 2.2 为什么不需要"电压重建"

早期路线图里写过"用占空比 + Vbus 重建相电压"。推导后确认**不必要**：

SVPWM 注入的零序分量 `v0` 在三相等量叠加：

```
va = vα + v0,  vb = vβ' + v0,  vc = vc' + v0

Clarke:  (2/3)(va − vb/2 − vc/2) = 原式 + (2/3)(v0 − v0/2 − v0/2) = 原式 + 0
```

**零序在 αβ 上完全抵消**，所以"占空比重建 → Clarke"与直接用 `vα/vβ` 等价。
直接用控制器输出更简单、无量化误差。

> 唯一差异：占空比重建能反映"最小脉宽截断/过调制"，而 `vα/vβ` 是理想指令。
> 在 `m ≤ 0.95` 的正常工作区内两者一致，因此不做重建。

**死区补偿**同理降级为可选（见第 8 节），先量出误差再决定。

### 2.3 为什么用 PLL 而不是 `atan2`

| 方法 | 问题 |
|---|---|
| `atan2(−eα, eβ)` | 每拍独立求解，`e` 的噪声直接变成角度抖动 → 转矩脉动；低速时信噪比更差 |
| **PLL** | 带惯性的跟踪，自带低通；输出连续的角度与转速；对瞬时异常鲁棒 |

### 2.4 关键公式与符号约定

反电动势与角度的关系（`ψf` 为永磁磁链，`ωe` 为电角速度）：

```
eα = −ωe·ψf·sin(θe)
eβ = +ωe·ψf·cos(θe)
```

旋转到估计坐标系（`θ̂`）：

```
ed =  eα·cosθ̂ + eβ·sinθ̂ = ωe·ψf·sin(θ̂ − θe)     ← 误差项
eq = −eα·sinθ̂ + eβ·cosθ̂ = ωe·ψf·cos(θ̂ − θe)
```

- `θ̂ = θe` 时：`ed = 0`、`eq = ωe·ψf`
- **PLL 的目标就是让 `ed → 0`**
- `eq` 可用于估算转速幅值（辅助判断"反电动势够不够大"）

### 2.5 复用现有代码

| 现有模块 | 复用方式 |
|---|---|
| `alg_pll.c` | 新增 `alg_pll_step_err(p, err, dt)`：直接吃 `ed`，跳过角度环绕 |
| `alg_clarke()` | 由 `ia/ib` 得 `iα/iβ`（`alg_foc.c` 已有） |
| `alg_foc` 的 `vα/vβ` | 观测器的电压输入（需在 `alg_foc` 里暴露） |
| `wave`/`rip`/`sstep` | 验收工具 |

## 3. 实施步骤

每个步骤有独立验收标准，未达标不得进入下一步。

### S10.1 观测器基础设施（不接入控制）

| 项 | 内容 |
|---|---|
| 新增 | `User/Alg/alg_obs.c/.h`：反电动势估计 + `ed/eq` 计算 + 一阶低通 |
| 修改 | `alg_pll` 增加 `alg_pll_step_err()` |
| 修改 | `alg_foc` 暴露最近一次的 `vα/vβ`（供观测器使用） |
| 新增命令 | `obs`：显示 `eα/eβ/ed/eq/θ̂/ω̂`、编码器角度、角度差 |
| 新增波形 | ch19 = 观测器角度，ch20 = 角度误差（`WAVE_CH` 19 → 21） |
| **验收** | `obs` 有合理数值；**电机行为与改动前完全一致**（观测器不参与控制） |

### S10.2 影子模式：量化角度误差（**关键门槛**）

| 项 | 内容 |
|---|---|
| 内容 | 编码器驱动 FOC，观测器并行运行，只统计 |
| 命令 | `obs on/off`、`obs bw <hz>`、`obs r <ohm>`、`obs l <mh>` |
| 测试点 | 300 / 500 / 800 / 1200 / 1800 rpm，每个测 10 s |
| 记录 | 角度误差的**均值 / 峰峰 / 最大**、转速误差百分比 |
| **验收门槛** | 500 rpm 以上：角度误差 **< 5°**，转速误差 **< 3%** |
| 不达标 | 改观测器结构（S10.2b：磁链积分 或 Luenberger），**仍在影子模式下验证** |

### S10.3 观测器整定

| 项 | 内容 |
|---|---|
| 扫描 | PLL 带宽 20 / 40 / 80 / 150 Hz；`R` 标定值 2.0 / 2.3 / 2.6 Ω |
| 判据 | 角度误差最小，且高速段不抖 |
| 产出 | 参数写入 `board_cfg.h`，并在本文档记录最终值与依据 |

### S10.4 I/f 开环启动

| 项 | 内容 |
|---|---|
| 新增 | `alg_if.c/.h`：按设定电频率旋转电流矢量（可复用 `alg_vf` 思路，但控制的是电流矢量角度） |
| 参数 | 起始 2 Hz、加速度 20~50 Hz/s、电流 0.3~0.5 A |
| 验收 | **连续 10 次**从静止起动到 300 rpm 不失步、不反转 |

### S10.5 切换与闭环无感

| 项 | 内容 |
|---|---|
| 切换条件 | `\|θ̂ − θ_if\| < 25°` 且 `\|e\| > 0.5 V` 且持续 20 ms |
| 切换动作 | 渐变频权重 `θ = (1−w)·θ_if + w·θ̂`，`w` 在 100 ms 内 0→1 |
| 命令 | `sfoc on/off` 开启无感闭环 |
| 验收 | 300~1800 rpm 双向稳定；`rip` 的 iq 纹波与有感模式对比记录 |

### S10.6 保护适配与收尾

| 项 | 内容 |
|---|---|
| 失步检测 | `\|ed\| > 阈值` 持续 50 ms → 退 I/f；连续 3 次 → FAULT |
| 堵转保护 | 无感模式下 `spd` 来自观测器，阈值需重新标定（否则易误判） |
| 编码器优先 | 检测到有效编码器时默认用编码器（可用 `sfoc` 强制无感） |
| 文档 | `docs/00`、`01`、`31`、`32`、`34` 同步更新 |

## 5. 测试计划

| 层 | 内容 |
|---|---|
| **主机测试** | 用已知 `θ(t)`、`ω` 正演生成 `vα/vβ`、`iα/iβ`（含噪声），检查观测器反推的 `θ̂` 误差 < 0.5°；R 偏差 ±20% 时的鲁棒性；PLL 收敛时间 |
| **硬件·影子** | 全速域 300~1800 rpm 扫频，输出角度误差表（**最关键的验证**） |
| **硬件·无感** | 拔掉编码器，300~1800 rpm 运行；对比 `rip` 纹波、`sstep` 响应、最高转速 |
| **回归** | 6 类保护在无感模式下逐一复测 |

### 对比指标（有感 vs 无感）

| 指标 | 有感（基线） | 无感目标 |
|---|---|---|
| 800 rpm iq 纹波 | 0.06 A | < 0.15 A |
| 800 rpm 转速脉动 | 11 rpm | < 30 rpm |
| 最低转速 | 30 rpm | 300 rpm（以下 I/f） |
| 最高转速 | ~1800 rpm | ≥ 1500 rpm |
| 角度误差 | 0.1° | < 5° |

## 6. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| 低速角度误差大 | 高 | 本来就由 I/f 覆盖；切换点定在 300 rpm |
| **切换失步** | **高** | 渐变频权重 + 退回 I/f 的两级降级 |
| R 温漂（±20%） | 中 | 先标定；后续可在低速段在线辨识 |
| `di/dt` 噪声 | 中 | L 仅 0.5 mH，L·di/dt 占比小（约 0.007 V）；再加低通 |
| 死区误差 | 中 | 先不补偿，用影子模式量出影响再决定 |
| ISR 超时 | 低 | FOC 现用 6.5 µs/50 µs，观测器约 +2~3 µs |
| 无感下堵转误判 | 中 | S10.6 重新标定堵转判据 |

## 8. 暂不做的项

| 项 | 原因 |
|---|---|
| 相电压采样电路 | 决策 3：不改硬件；先量误差再评估 |
| 死区补偿 | 先测出不补偿时的误差；若影响 <5° 则不做 |
| HFI 高频注入 | 本机无凸极（表贴磁钢），不可行 |
| 参数在线辨识（R/L） | 属于增强项，验收通过后再考虑 |
| 编码器删除 | 决策 1：保留，作为可选与真值参考 |

## 9. 与早期路线图的差异（保留决策脉络）

| 早期（`33` 第 5 节） | 本方案 | 原因 |
|---|---|---|
| S10.1 电压重建 + 死区补偿 | **取消重建**；死区补偿降为可选 | `vα/vβ` 已够用，零序在 αβ 抵消 |
| S10.2 观测器 + PLL（含整定） | 拆为 S10.1 基础设施 → **S10.2 影子验证** → S10.3 整定 | 先量化误差，再接入控制 |
| S10.3 I/f + 切换 | 拆为 S10.4 I/f、S10.5 切换 | 两种失败模式，分开验证 |
| S10.4 失步检测 | 并入 S10.6，两级降级 | 丢锁应能自动退回，而非直接跳闸 |
| S10.5 有感 vs 无感对比 | 并入验收 | 对比是验收手段，不是开发步骤 |
