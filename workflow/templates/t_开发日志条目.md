## 写作要求速查

| 要求 | 说明 |
|---|---|
| 必须有数据 | 没有数据的条目 = 日记，不是日志 |
| 保留原始日志片段 | 便于事后重新分析（不要"整理"掉细节） |
| 记录偶发问题 | 偶发问题最值钱（"必现"的问题很快会被修掉） |
| 记录被推翻的假设 | 这是最高价值的知识 |
| 附固件版本 | `#163` 这样的锚点，否则无法追溯 |
| 单位 | 数值必须带单位 |
