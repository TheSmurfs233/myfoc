# 阶段方案模板

> 文件：`docs/4x_方案_S<n>_<阶段名>.md` 或直接写在 `01_项目进度` 的附注里（小阶段）。
> **不写方案的阶段不允许开工。**

---


---

## 写作要求

| 要求 | 说明 |
|---|---|
| 目标必须可量化 | "改善性能"不合格；"稳态误差 < 1%" 合格 |
| 必须写非目标 | 否则执行中会不断加需求 |
| 必须有备选路线 | 否则无法判断当前选择是否合理 |
| 必须写"怎么验证" | 这是方案里最容易漏、也最重要的一节 |
| 必须写回退方案 | 新功能要能一键关掉 |
