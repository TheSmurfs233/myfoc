## S0.5：硬件参数全部闭环（读数据手册 + 逐条核对原理图）

- **驱动 EG3033**：三相 P/N MOS 驱动，`HIN→P管`、`LIN→N管`，内部 DT=60ns，**HIN=LIN 同时为 1 或 0 都双关（互锁）** → TIM1 互补输出天然兼容，不需取反。HO 灌电流仅 40mA（P 管关断慢）
- **MOS AO4606**：30V/6A，Ciss 255pF，Qg 5.2nC，Vgs(th) 1.2~2.4V
- **死区定 DTG=4（23.5ns 标称）**：P管关断 ~80ns < N管开通到 Vth ~157ns → 自然死区 ~96ns；TIM1 设任何 ≤60ns 都被 EG3033 的 60ns 吞掉 → **实际生效 60ns**（用户要求"设小一点"，正确）
- **电流采样**：Rshunt 实焊 **25mΩ**（原理图标 10mΩ）；INA240 **REF1=AGND / REF2=A3V3 → VREF=1.65V**（双向，零码 2048）→ **0.645mA/LSB，量程仅 ±1.32A**
- **母线 12V**：R20 12k / R21 2k = 1/7 分压，5.64mV/LSB，接 **PA1**（CubeMX 尚未配 ADC）
- **MT6701 SSI**：24bit 帧（D[13:0] 角度 + Mg[3:0] 状态 + CRC[5:0] poly X⁶+X+1）；**DO 上升沿变化、下降沿采样 → SPI Mode 1，现有配置正确不用改**；TCLK≥64ns → SCK ≤15.6MHz，当前 10.625MHz 安全
- **引脚映射**：PA8/9/10=HIN1/2/3(CH1/2/3)，PA7/PB0/PF0=LIN1/2/3(CH1N/2N/3N)，PA4/5/6=ISU/ISV/ISW，PA0=KEY(10k上拉,按下低)，PF1=LED(低亮)，PA15=CSN
- **重要发现**：板载 CH340N 接的是 **USART2(PA2/PA3)**，而 USART1(PB6/PB7) 接 CN3 排针 → 用户选 USART1（外接 USB-TTL），零 CubeMX 改动
